# 期末复习整理说明

本目录是按 `Compile`、`Network`、`RISC-V` 三个课程文件夹整理出来的复习包。

## 已处理范围

- `Compile`: 处理主目录下的编译原理课件 PDF/PPTX, 包括编程语言、编译器结构、词法、语法、语义、中间代码、运行时、优化、目标代码生成和 review.
- `Network`: 处理主目录下第 0 到第 7 章网络课件 PDF, 并参考 homework 目录里的章节题目来设计题型。
- `RISC-V`: 处理主目录下计算机组成与体系结构/RISC-V 相关 PDF, 包括系统概论、数据表示与运算、指令系统、总线与 I/O、存储层次、CPU, 以及 RISC-V Green Card.

## 已排除范围

按你的要求，实验不考，所以没有把这些内容纳入主复习材料：

- `lab`、`Labs`、实验说明、抓包文件、eNSP 安装包与安装指南。
- 网络编程 project 和课程论文材料。
- 参考书整本 PDF 没有逐页整理, 因为它们不是课件主线；需要时可以作为查漏补缺。

## 推荐复习顺序

1. 先看每门课的 `完整讲解.md`, 建立主线。
2. 遇到看不懂的重点名词, 点资料里的链接进入 `重点难点详解`, 从零基础补概念和做题步骤。
3. 再做对应的 `期末题目.md`, 不会的题回到讲解或重点难点详解里查。
4. 每门课最后再背“高频考点清单”和公式。
