# RISC-V 组成与体系结构期末题目

说明: 题目覆盖系统概论、数据表示与运算、指令系统、总线与 I/O、存储层次、CPU 与流水线。每题后给答案要点。

## 一、系统概论

1. 简述存储程序思想的三个核心内容。

答案要点: 五大部件；指令和数据二进制表示；程序和数据预先存入存储器并自动执行。

2. 区分计算机系统结构、计算机组成和计算机实现。

答案要点: 系统结构是程序员可见机器属性/ISA；组成是系统结构的逻辑实现和部件组织；实现是器件工艺和物理实现。

3. 判断: “是否设置乘法指令”属于系统结构还是组成？“乘法指令用专用乘法器实现”属于什么？

答案要点: 是否设置乘法指令属于系统结构；用专用乘法器还是加法移位实现属于组成。

4. 什么是透明性？举一个例子。

答案要点: 某细节真实存在但对某层用户不可见。例: Cache 对应用程序员透明。

5. 什么是系列机？为什么系列机有利于软件兼容？

答案要点: 具有相同/相近系统结构的一系列机器；ISA 相同则目标程序可在系列内运行。

6. 比较自上而下、自下而上和中间开始的系统设计方法。

答案要点: 自上而下从应用出发；自下而上从器件出发；中间开始从软硬接口 ISA 出发, 兼顾软件和硬件。

7. 写出 Amdahl 定律公式并解释各参数。

答案要点: `Sn = 1 / ((1-Fe)+Fe/Se)`。Fe 是可改进部分原时间占比, Se 是该部分加速比。

8. 某部件占总时间 40%, 该部件加速 10 倍, 总加速比是多少？

答案要点: `1/(0.6+0.4/10)=1/0.64=1.5625`.

9. 若希望系统总加速比达到 4, 某部分加速 25 倍, 该部分原时间占比至少多少？

答案要点: `4=1/((1-Fe)+Fe/25)`, 得 `Fe≈0.78125`, 即约 78.1%。

10. 写出 CPU 性能公式。

答案要点: `CPU time = IC*CPI*Clock Cycle Time = IC*CPI/Clock Rate`.

11. 一程序执行 2e9 条指令, CPI=1.5, 主频 3 GHz, CPU 时间是多少？

答案要点: `2e9*1.5/3e9 = 1 s`.

12. Flynn 分类包括哪四类？

答案要点: SISD、SIMD、MISD、MIMD。

13. 流水线、阵列处理机、多处理机分别主要利用哪种并行途径？

答案要点: 流水线是时间重叠；阵列处理机是资源重复；多处理机是资源共享/多指令多数据并行。

## 二、数据表示

14. 8 位补码能表示的数值范围是多少？

答案要点: -128 到 127。

15. 写出十进制 -18 的 8 位补码。

答案要点: 18 为 `00010010`, 取反 `11101101`, 加 1 得 `11101110`。

16. 8 位补码 `11110101` 表示十进制多少？

答案要点: 最高位为 1, 取反加 1 得 `00001011`=11, 所以是 -11。

17. 原码、反码、补码中, 哪些有 +0 和 -0？

答案要点: 原码和反码有 +0/-0；补码只有一个 0。

18. 补码加法中如何判断溢出？

答案要点: 同号相加得异号则溢出；或最高位进位与次高位进位不同。

19. 8 位补码 `01010000 + 01010000` 是否溢出？

答案要点: 两个正数相加结果 `10100000` 为负, 溢出。

20. IEEE 754 单精度浮点数由哪些字段组成？

答案要点: 1 位符号, 8 位阶码, 23 位尾数 fraction, 阶码偏置 127。

21. 单精度规格化浮点数的值如何计算？

答案要点: `(-1)^S * 1.fraction * 2^(E-127)`.

22. 将十进制 5.5 表示为二进制规格化形式。

答案要点: `5.5 = 101.1b = 1.011b * 2^2`.

23. 偶校验要求什么？数据 `1011001` 的偶校验位是多少？

答案要点: 让 1 的总数为偶数。数据中有 4 个 1, 校验位为 0。

24. 奇偶校验能否纠正错误？

答案要点: 不能纠正, 只能检测部分错误；奇数位错误可检, 偶数位错误可能漏检。

## 三、数据运算

25. 写出 1 位全加器的和位与进位表达式。

答案要点: `Si=Ai xor Bi xor Ci`; `Ci+1=AiBi+(Ai xor Bi)Ci`.

26. 串行加法器和并行加法器的区别是什么？

答案要点: 串行加法器一个全加器逐位计算, 硬件少速度慢；并行加法器多个全加器同时处理, 硬件多速度快。

27. 行波进位加法器的主要性能瓶颈是什么？

答案要点: 进位必须逐级传播, 位数越多延迟越大。

28. 先行进位中 Gi 和 Pi 的含义是什么？

答案要点: `Gi=AiBi` 表示本位产生进位；`Pi=Ai xor Bi` 表示本位传递进位。

29. 逻辑右移和算术右移有什么不同？

答案要点: 逻辑右移高位补 0；算术右移高位补符号位。

30. Booth 乘法中 `01` 和 `10` 分别对应什么操作？

答案要点: `01` 加被乘数；`10` 减被乘数；`00/11` 不操作。

31. Booth 乘法为什么适合处理连续 1？

答案要点: 连续 1 可转换为一次加和一次减, 减少多次加法。

32. ALU 通常支持哪些操作？

答案要点: 算术、逻辑、比较、移位等。

## 四、指令系统与 RISC-V

33. 什么是 ISA？为什么说它是软硬件接口？

答案要点: ISA 定义机器级程序可见的指令、寄存器、寻址、数据类型等；编译器/程序通过它使用硬件, 硬件按它实现功能。

34. 计算有效地址: 基址寄存器 Rb=1000, 变址寄存器 Ri=20, 位移量 d=8, 若 `EA=Rb+Ri+d`, EA 是多少？

答案要点: 1028。

35. 立即寻址和直接寻址有什么区别？

答案要点: 立即寻址操作数本身在指令中；直接寻址指令地址字段给出操作数内存地址。

36. 相对寻址的 EA 如何计算？

答案要点: `EA = PC + offset`。

37. 指令格式设计要考虑哪些因素？

答案要点: 操作码位数、地址码位数、指令长度、寻址灵活性、译码复杂度、使用频率。

38. 什么是扩展操作码？

答案要点: 高频或多地址指令用较短操作码, 低频或少地址指令借用部分地址字段扩展操作码, 以降低平均指令长度。

39. Huffman 编码思想用于指令编码时有什么好处和代价？

答案要点: 高频指令短码可降低平均长度；代价是指令长度不定和译码复杂。

40. 比较 RISC 和 CISC。

答案要点: RISC 指令简单规整、load/store、寄存器多、流水友好；CISC 指令复杂、格式多、单条可完成复杂操作但硬件复杂。

41. RISC 设计的关键技术有哪些？

答案要点: load/store、大量寄存器、简单寻址、规整格式、流水线、编译优化。

42. RISC-V 中 `x0` 有什么特殊性？

答案要点: 恒为 0, 写入无效, 读出为 0。

43. RISC-V `add x5, x6, x7` 属于什么类型？语义是什么？

答案要点: R-type。`x5 = x6 + x7`。

44. RISC-V `lw x5, 8(x6)` 的语义是什么？

答案要点: 从内存地址 `x6+8` 读取一个 word 到 `x5`。

45. RISC-V `sw x5, 12(x6)` 的语义是什么？

答案要点: 把 `x5` 的 word 写到内存地址 `x6+12`。

46. RISC-V 条件分支通常使用什么寻址？

答案要点: PC 相对寻址。

## 五、总线与 I/O

47. I/O 系统由哪些部分组成？

答案要点: 外设、设备控制器、总线、I/O 软件、CPU/主存接口、中断/DMA 等控制机制。

48. RAID 0、RAID 1、RAID 5 的主要特点分别是什么？

答案要点: RAID0 条带化无冗余性能高；RAID1 镜像可靠但空间利用低；RAID5 分布式奇偶校验, 可容忍一盘故障。

49. 总线按功能可分为哪三类？

答案要点: 数据总线、地址总线、控制总线。

50. 一条 64 bit 总线, 频率 100 MHz, 每周期传一次, 理论带宽是多少？

答案要点: `64*100MHz/8 = 800 MB/s`。

51. 集中式总线仲裁和分布式总线仲裁有什么区别？

答案要点: 集中式由一个仲裁器决定；分布式由各模块协商竞争, 无单一中心。

52. 同步总线和异步总线的区别是什么？

答案要点: 同步总线由公共时钟协调；异步总线用握手信号协调。

53. 程序查询方式 I/O 的缺点是什么？

答案要点: CPU 反复轮询设备状态, 浪费 CPU 时间。

54. 中断方式比查询方式好在哪里？

答案要点: 设备准备好时才通知 CPU, CPU 可在等待期间执行其他任务。

55. DMA 适合什么场景？它为什么能减轻 CPU 负担？

答案要点: 适合大块数据传输；DMA 控制器直接在外设和主存间传数据, CPU 只初始化和处理完成中断。

## 六、存储器层次结构

56. 存储器层次结构要解决哪三者矛盾？

答案要点: 速度、容量、价格。

57. 什么是时间局部性和空间局部性？

答案要点: 时间局部性是刚访问过的内容近期可能再访问；空间局部性是邻近地址近期可能被访问。

58. 某程序访存 1000 次, Cache 未命中 50 次, 命中率是多少？

答案要点: `(1000-50)/1000 = 95%`。

59. Cache 命中率 0.96, Cache 时间 40 ns, 主存时间 160 ns, 平均访问时间是多少？

答案要点: `TA=0.96*40+0.04*160=44.8 ns`。

60. 上题访问效率是多少？

答案要点: `e=40/44.8≈89.3%`。

61. SRAM 和 DRAM 的主要区别是什么？

答案要点: SRAM 用触发器, 快贵, 常作 Cache；DRAM 用电容, 需刷新, 容量大便宜, 常作主存。

62. Cache 映像方式有哪三种？

答案要点: 全相联、直接映像、组相联。

63. 直接映像中, 主存块号 B 映像到 Cache 块号 b 的公式是什么？

答案要点: `b = B mod Cache块数`。

64. 组相联中, 主存块映像到 Cache 组号的公式是什么？

答案要点: `set = B mod Cache组数`。

65. 某 Cache 共有 16 块, 2 路组相联, 每块 32 Byte。主存地址 129 所在主存块应映像到哪一组？

答案要点: 主存块号 `floor(129/32)=4`; Cache 组数 `16/2=8`; 组号 `4 mod 8 = 4`。

66. 32 位地址, Cache 大小 16 KB, 块大小 64 Byte, 直接映像。求 offset、index、tag 位数。

答案要点: 块大小 64B -> offset 6 位。Cache 行数 `16KB/64B=256` -> index 8 位。tag `32-6-8=18` 位。

67. 32 位地址, Cache 大小 32 KB, 块大小 64 Byte, 4 路组相联。求 offset、set index、tag 位数。

答案要点: offset 6 位。总行数 `32KB/64=512`; 组数 `512/4=128` -> set index 7 位。tag `32-6-7=19` 位。

68. 全相联、直接映像、组相联的优缺点如何比较？

答案要点: 全相联冲突少但硬件复杂；直接映像简单快但冲突多；组相联折中。

69. LRU 替换算法的思想是什么？

答案要点: 替换最长时间未被访问的块。

70. Write-through 和 write-back 有什么区别？

答案要点: 写直达每次写 Cache 同时写主存；写回只写 Cache, 替换脏块时写主存。

71. 虚拟地址分页系统中, 页内偏移在地址转换时是否改变？

答案要点: 不改变。虚页号变为物理页框号, 页内偏移保持。

72. TLB 的作用是什么？

答案要点: 缓存页表项, 加速虚拟地址到物理地址转换。

73. 什么是缺页？

答案要点: 访问的虚拟页不在主存, 需要操作系统从磁盘调入。

## 七、CPU 与控制器

74. CPU 主要由哪些部分组成？

答案要点: 运算器、控制器、寄存器组、内部总线等。

75. 一条指令通常经历哪些阶段？

答案要点: 取指、译码、取操作数、执行、访存、写回。

76. RISC-V R 型指令的数据通路大致是什么？

答案要点: 取指 -> 译码读 rs1/rs2 -> ALU 运算 -> 写 rd。

77. RISC-V load 指令的数据通路大致是什么？

答案要点: 读 rs1 -> 立即数扩展 -> ALU 计算地址 -> 数据存储器读 -> 写 rd。

78. 控制器要产生哪些典型控制信号？

答案要点: RegWrite、MemRead、MemWrite、MemToReg、ALUSrc、Branch、PCSrc、ALUOp 等。

79. 硬布线控制和微程序控制有什么区别？

答案要点: 硬布线用组合逻辑直接产生控制信号, 快但修改难；微程序用控制存储器中的微指令产生控制信号, 灵活但可能慢。

80. 水平型微指令和垂直型微指令有什么区别？

答案要点: 水平型控制位多、并行性强、字长长；垂直型编码程度高、字长短、需译码、并行性较弱。

81. 单周期 CPU 的主要缺点是什么？

答案要点: 时钟周期必须按最慢指令设置, 简单指令浪费时间。

82. 多周期 CPU 相比单周期 CPU 的优点是什么？

答案要点: 指令分阶段执行, 不同指令可用不同周期数, 周期更短, 功能部件可复用。

83. 五级流水线通常包括哪五级？

答案要点: IF、ID、EX、MEM、WB。

84. 流水线理想加速比为什么接近流水级数？

答案要点: 多条指令不同阶段重叠执行, 稳态下每周期完成一条指令, 吞吐率提高约 k 倍。

85. 什么是结构冒险？如何解决？

答案要点: 多条指令同时争用同一硬件资源；可增加资源或暂停。

86. 什么是数据冒险？如何解决？

答案要点: 后续指令需要前一指令尚未写回的结果；可转发或插入停顿。

87. 什么是控制冒险？如何解决？

答案要点: 分支导致下一条 PC 不确定；可分支预测、延迟槽、暂停或冲刷流水线。

88. 为什么 load-use 冒险即使有转发也常需停顿？

答案要点: load 的数据通常到 MEM 阶段末才可用, 紧随其后的指令 EX 阶段太早需要该数据。

89. 流水线 CPI 如何表示？

答案要点: `CPI = 理想CPI + 每条指令平均停顿周期数`。

90. 某 5 级流水线理想 CPI=1, 20% 指令为分支, 分支错误率 10%, 每次错误惩罚 2 周期, 忽略其他停顿, 平均 CPI 是多少？

答案要点: 额外 CPI `0.2*0.1*2=0.04`; 总 CPI `1.04`。

## 八、综合题

91. 说明“同一系统结构可有不同组成”的含义, 举例。

答案要点: ISA 相同但内部组织不同, 如同一 ISA 的处理器可有无 Cache、单级/多级 Cache、不同流水线。程序能运行但性能不同。

92. 某程序原执行时间 100s, 其中 60s 可通过新算法加速 5 倍, 其余不变。新执行时间和加速比是多少？

答案要点: 新时间 `40+60/5=52s`; 加速比 `100/52≈1.923`。

93. 某机器 IC 减少 20%, 但 CPI 从 1.2 增到 1.5, 主频不变, 性能是否提升？

答案要点: 原时间比例 `IC*1.2`; 新时间 `0.8IC*1.5=1.2IC`; 不变。

94. 若一个 32 位虚拟地址系统页大小 4 KB, 虚拟地址中页内偏移多少位？虚页号多少位？

答案要点: 4KB=2^12, offset 12 位, VPN 20 位。

95. 解释 Cache 和虚拟存储器的区别。

答案要点: Cache 目标是提高速度, 主要硬件实现, 对系统和应用多透明；虚拟存储目标是扩大地址空间, 软件为主硬件辅助, 对应用透明但 OS 管理。

96. 比较程序查询、中断、DMA 三种 I/O 方式的 CPU 参与程度。

答案要点: 查询最高, CPU 忙等；中断中等, 准备好再处理；DMA 最低, 大块传输由 DMA 控制器完成。

97. 为什么 RISC 更适合流水线？

答案要点: 指令格式规整、操作简单、load/store 分离、执行阶段均衡, 控制逻辑简单。

98. 对如下指令序列指出数据冒险并给出解决办法:

```text
add x1, x2, x3
sub x4, x1, x5
```

答案要点: `sub` 读 x1, 依赖前一条 add 结果。可用 EX/MEM 到 EX 转发, 或插入停顿。

99. 对如下序列指出 load-use 冒险:

```text
lw  x1, 0(x2)
add x3, x1, x4
```

答案要点: add 立即使用 load 结果, 通常需插入 1 个 stall, 再转发。

100. 如果考试只让你用一句话说明 RISC-V 的设计风格, 你会怎么说？

答案要点: RISC-V 是开放、模块化、load/store、指令格式规整、适合流水线和编译器优化的 RISC 指令集。
