## 新资料补充: 计算题和协议流程题

根据你给的 `计算机网络` 文件夹，补充资料和往年题更偏“公式计算 + 协议过程解释”。做题时先判断层次，再判断是计算题还是流程题。

- 时延题先统一单位，再分清 [传输时延](?doc=deep-dive&anchor=network-delay#reader) 和传播时延。传输是把比特推上链路，传播是信号在介质中走。
- 信道容量题先看题目是否说有噪声。无噪声且给信号级数用 Nyquist；有噪声且给 SNR 用 Shannon；给 dB 要先换成普通信噪比。
- 链路层题常考 CRC、停等、GBN、SR。GBN 出错后从错帧开始重传，SR 只重传错帧，但窗口不能超过序号空间一半。
- MAC 题要会比较 CSMA/CD 和 CSMA/CA。无线网络难以碰撞检测，隐藏终端也会导致冲突，所以使用碰撞避免和 ACK。
- 网络层题高频是子网、CIDR、最长前缀匹配、IP 分片。分片偏移单位是 8 Byte，除最后一片外数据长度要取 8 的倍数。
- TCP 题高频是 seq/ack、三次握手、四次挥手、流量控制和拥塞控制。发送窗口等于 `min(rwnd, cwnd)`。
- 应用层题要会按顺序写 DNS、HTTP、DHCP。浏览器访问网页常串起 DNS、TCP、HTTP、IP、ARP、以太网多个层次。

## 0. 一句话总览

计算机网络研究的是: 不同主机如何通过协议分层、交换、寻址、路由、可靠传输和应用协议完成通信。

复习主线:

```text
应用产生数据
-> 传输层把进程到进程的数据传好
-> 网络层把主机到主机的包送到目的网络
-> 数据链路层把相邻节点之间的帧传好
-> 物理层把比特变成信号
```

每一层都只解决自己这一层的核心问题, 并向上一层提供服务。

## 1. 网络概论与体系结构

### 1.1 什么是计算机网络

计算机网络是由通信链路和交换设备连接起来的一组自治计算机系统。网络的核心目标是资源共享和信息传递。

从 Internet 的角度看, 网络包括:

- 网络边缘: 主机、服务器、手机、浏览器、应用。
- 网络核心: 路由器、交换机、传输链路。
- 接入网络: 家庭宽带、校园网、蜂窝网络、Wi-Fi 等。

### 1.2 分组交换与电路交换

电路交换:

- 通信前建立专用电路。
- 通话期间资源独占。
- 适合传统电话。
- 缺点是突发数据会浪费带宽。

分组交换:

- 数据被切分为 packet。
- 每个 packet 独立转发, 共享链路。
- Internet 的核心方式。
- 优点是资源利用率高；缺点是会有排队时延、丢包和乱序。

### 1.3 时延与吞吐量

一个分组从一端到另一端的总时延通常包括:

- 处理时延 processing delay: 路由器检查首部、查表。
- 排队时延 queuing delay: 在队列中等待发送。
- 传输时延 transmission delay: 把 L bit 推上链路的时间, `L/R`。
- 传播时延 propagation delay: 信号在介质中传播的时间, `d/s`。

所以:

```text
总时延 = 处理 + 排队 + 传输 + 传播
```

吞吐量 throughput 是单位时间真正交付的数据量。端到端吞吐量通常受瓶颈链路限制。

### 1.4 协议、服务与分层

协议定义通信实体之间交换报文的格式、次序以及收到报文后的动作。

分层的好处:

- 每层关注自己的问题。
- 上层不必知道下层细节。
- 协议可替换, 便于标准化。

OSI 七层:

```text
应用层 表示层 会话层 传输层 网络层 数据链路层 物理层
```

TCP/IP 常用五层:

```text
应用层 传输层 网络层 数据链路层 物理层
```

封装过程: 应用数据往下走, 每层加自己的首部；接收端往上走, 每层去掉对应首部。

## 2. 物理层

### 2.1 物理层解决什么

物理层负责在传输介质上传输原始 bit 流。它关心:

- 机械特性: 接口形状、引脚。
- 电气特性: 电压、电平、速率。
- 功能特性: 每条线的功能。
- 规程特性: 信号出现顺序。

### 2.2 信道、带宽与数据率

带宽 bandwidth 表示信道可通过的频率范围, 常以 Hz 表示。数据率 bit rate 表示每秒传输多少 bit, 常以 bps 表示。

奈奎斯特定理用于理想无噪声信道:

```text
最大数据率 = 2B log2(V)
```

- B: 信道带宽
- V: 信号离散电平数

香农定理用于有噪声信道:

```text
最大数据率 = B log2(1 + S/N)
```

S/N 常以 dB 给出:

```text
dB = 10 log10(S/N)
```

### 2.3 编码与调制

数字数据可以编码为数字信号:

- NRZ: 0/1 用不同电平表示, 简单但同步困难。
- NRZI: 通过是否翻转表示 bit, 常用于磁盘/链路编码。
- Manchester: 每个 bit 中间必有跳变, 同步好但带宽开销大。
- Differential Manchester: 用跳变方向/是否起始跳变表达数据, 抗极性反接。

数字数据也可调制为模拟信号:

- ASK: 幅移键控, 改变幅度。
- FSK: 频移键控, 改变频率。
- PSK: 相移键控, 改变相位。
- QAM: 同时改变幅度和相位, 可提高每个符号携带的 bit 数。

### 2.4 多路复用

多路复用是让多个通信共享一条物理链路:

- FDM: 频分复用, 不同用户占不同频段。
- TDM: 时分复用, 不同用户占不同时间片。
- WDM: 波分复用, 光纤中的不同波长。
- CDM/CDMA: 码分复用, 用户用不同码片区分。

### 2.5 传输介质和设备

传输介质:

- 双绞线: 便宜, 常用于以太网。
- 同轴电缆: 抗干扰较好。
- 光纤: 带宽大、抗干扰强、远距离。
- 无线: 灵活, 但易受干扰和衰减。

物理层设备:

- 中继器 repeater: 再生信号, 延长距离。
- 集线器 hub: 多端口中继器, 所有端口共享冲突域。

## 3. 数据链路层

### 3.1 数据链路层功能

数据链路层负责相邻节点之间的帧传输。主要功能:

- 成帧 framing
- 差错检测/纠正
- 流量控制
- 可靠传输
- 介质访问控制, 在广播链路中尤其重要

数据链路层传输单位是 frame。

### 3.2 成帧

成帧要让接收方知道一帧从哪里开始、哪里结束。常见方法:

- 字节计数法: 首部写长度。
- 字节填充: 特殊字节作为边界, 数据中出现特殊字节就转义。
- 比特填充: 如 HDLC 中 `01111110` 作标志, 数据中连续五个 1 后插入 0。
- 物理层编码违例。

### 3.3 差错控制

差错检测:

- 奇偶校验: 简单, 能检测奇数个 bit 错误。
- 校验和 checksum: 常用于 IP/TCP/UDP。
- CRC: 把 bit 串看成多项式, 用生成多项式除, 余数作为校验码, 检错能力强。

纠错:

- 海明码 Hamming code 可定位并纠正单 bit 错误。

### 3.4 停等协议

Stop-and-Wait:

1. 发送方发一帧。
2. 等 ACK。
3. 超时未收到 ACK 则重传。

它简单但效率低。链路带宽大、RTT 大时, 大部分时间都在等。

利用率近似:

```text
U = 发送一帧的时间 / (发送一帧时间 + RTT)
```

如果考虑确认帧、处理时延, 分母还要加上相应时间。

### 3.5 滑动窗口

滑动窗口允许发送方连续发送多个帧, 不必每帧都等 ACK。

Go-Back-N:

- 接收方只按序接收。
- 某帧丢失后, 后续乱序帧丢弃。
- 发送方超时后从丢失帧开始全部重传。
- 接收方窗口通常为 1。

Selective Repeat:

- 接收方可缓存乱序帧。
- 只重传丢失的帧。
- 效率高, 但实现复杂。
- 窗口大小需要限制, 避免序号混淆。

窗口大小与序号位数:

- GBN: 若序号空间为 `2^k`, 发送窗口最大 `2^k - 1`。
- SR: 发送/接收窗口最大通常不超过 `2^(k-1)`。

### 3.6 HDLC 与 PPP

HDLC 是面向比特的链路层协议, 使用标志序列和比特填充。

PPP 常用于点到点链路, 提供成帧、链路控制、网络层协议协商等能力, 但本身不提供可靠传输。

## 4. MAC 与局域网

### 4.1 MAC 要解决什么

广播信道中, 多个节点共享同一介质。如果两个节点同时发送, 会冲突。MAC 协议解决“谁什么时候发”。

常见类别:

- 信道划分: FDM/TDM/CDMA。
- 随机访问: ALOHA、CSMA、CSMA/CD、CSMA/CA。
- 轮流访问: 轮询、令牌。

### 4.2 CSMA/CD

CSMA/CD 用于传统共享式以太网:

- CSMA: 发送前先听信道。
- CD: 发送时检测冲突。
- 冲突后发送 jam signal, 停止发送, 按二进制指数退避等待后重试。

二进制指数退避:

```text
第 m 次冲突后, 从 [0, 2^k - 1] 中随机选 r
k = min(m, 10)
等待 r 个 slot time
```

现代交换式全双工以太网基本不再发生冲突, CSMA/CD 的考试意义主要在原理。

### 4.3 CSMA/CA

无线局域网无法可靠检测冲突, 所以使用 CSMA/CA:

- 发送前监听。
- 随机退避, 尽量避免同时发。
- 可使用 ACK 确认。
- 可选 RTS/CTS 减少隐藏终端问题。

隐藏终端: A 和 C 都能听到 B, 但彼此听不到, 同时给 B 发会冲突。

### 4.4 Ethernet

以太网帧主要字段:

- 目的 MAC 地址
- 源 MAC 地址
- 类型/长度
- 数据
- FCS

MAC 地址通常 48 bit, 用十六进制表示。交换机根据 MAC 地址转发帧。

### 4.5 交换机、网桥、路由器

集线器 hub:

- 物理层设备。
- 所有端口同一冲突域。

交换机 switch/网桥 bridge:

- 数据链路层设备。
- 根据 MAC 地址学习、过滤、转发。
- 每个端口通常是独立冲突域。

路由器 router:

- 网络层设备。
- 根据 IP 地址和路由表转发分组。

### 4.6 交换机学习与转发

交换机维护 MAC 表:

- 收到帧后学习源 MAC -> 入端口。
- 查目的 MAC:
  - 已知: 转发到对应端口。
  - 未知: 泛洪。
  - 若目的端口就是入端口: 过滤。

### 4.7 STP 与 VLAN

冗余链路会带来环路, 导致广播风暴。STP 通过阻塞部分端口构造无环生成树。

VLAN 把同一物理交换网络划分为多个逻辑广播域。802.1Q 在以太网帧中加入 VLAN tag。

VLAN 好处:

- 缩小广播域。
- 便于管理。
- 提高安全隔离。

Trunk 链路可承载多个 VLAN 的帧。

## 5. 网络层

### 5.1 网络层功能

网络层负责把分组从源主机送到目的主机。核心概念:

- forwarding 转发: 单个路由器根据转发表把包从输入端口送到输出端口。
- routing 路由: 全网范围计算路径, 生成转发表。
- switching 交换: 更泛化的数据转移概念, 在链路层和网络层都可能出现。

### 5.2 路由算法

Flooding 泛洪:

- 每个包往除入端口外所有端口转发。
- 简单但开销大, 需 TTL 或序号防止无限传播。

Dijkstra:

- 链路状态算法。
- 每个节点知道全网拓扑和链路代价。
- 计算从自己到所有节点的最短路径。

Distance Vector:

- 每个节点只知道到邻居的代价和邻居通告的距离向量。
- 基于 Bellman-Ford:

```text
D_x(y) = min_v { c(x,v) + D_v(y) }
```

- 问题: count-to-infinity。
- 改进: split horizon、poisoned reverse。

Link State:

- 每个路由器泛洪链路状态信息。
- 各自运行 Dijkstra。
- 收敛快, 开销较高。

### 5.3 IP 数据报

IPv4 数据报字段常考:

- Version
- Header Length
- Total Length
- Identification/Flags/Fragment Offset
- TTL
- Protocol
- Header Checksum
- Source IP
- Destination IP

TTL 每过一个路由器减 1, 防止分组无限循环。

### 5.4 分片

若数据报长度超过链路 MTU, 路由器可分片。相关字段:

- Identification: 同一原始数据报的分片相同。
- MF: more fragments, 后面是否还有分片。
- Fragment Offset: 分片偏移, 单位是 8 字节。

IPv6 中间路由器不分片, 由源主机处理路径 MTU。

### 5.5 IP 地址、子网与 CIDR

IPv4 地址 32 bit。CIDR 写法:

```text
192.168.1.0/24
```

表示前 24 bit 是网络前缀。

常见计算:

- 子网掩码: `/24` -> `255.255.255.0`
- 主机位数: `32 - 前缀长度`
- 可用主机数: `2^主机位数 - 2`, 点到点或特殊场景可能例外。
- 网络地址: IP 与掩码按位与。
- 广播地址: 网络位不变, 主机位全 1。

路由转发采用最长前缀匹配。

### 5.6 ARP、ICMP、NAT、IPv6

ARP:

- 已知同一局域网内目的 IP, 查询对应 MAC。
- 请求广播, 响应单播。

ICMP:

- 网络层控制报文。
- ping 使用 Echo Request/Reply。
- traceroute 利用 TTL 超时。

NAT:

- 多个内网主机共享公网 IP。
- 通过地址和端口转换维护映射表。
- 节省 IPv4 地址, 但破坏端到端透明性。

IPv6:

- 128 bit 地址。
- 首部简化。
- 支持扩展首部。
- 地址空间巨大, 不再依赖传统 NAT。

### 5.7 Internet 路由

RIP:

- 距离向量。
- 度量是跳数。
- 最大 15 跳, 16 表示不可达。

OSPF:

- 链路状态。
- 在自治系统内部使用。
- 支持区域划分。

BGP:

- 自治系统之间的路径向量协议。
- 关注策略, 不只是最短路径。

## 6. 传输层

### 6.1 传输层解决什么

网络层提供主机到主机通信, 传输层提供进程到进程通信。

关键概念:

- 端口 port
- socket
- 复用 multiplexing
- 分用 demultiplexing

套接字通常由 IP、端口、协议等标识。TCP 连接常由四元组标识:

```text
源 IP, 源端口, 目的 IP, 目的端口
```

### 6.2 UDP

UDP 特点:

- 无连接。
- 不保证可靠。
- 报文边界保留。
- 首部小, 延迟低。

适合 DNS、实时音视频、简单请求响应等。

UDP 首部字段:

- 源端口
- 目的端口
- 长度
- 校验和

### 6.3 TCP

TCP 特点:

- 面向连接。
- 可靠字节流。
- 有序交付。
- 流量控制。
- 拥塞控制。

TCP 可靠性机制:

- 序号 sequence number
- 确认 ACK
- 超时重传
- 累计确认
- 滑动窗口
- 快速重传

### 6.4 TCP 三次握手

三次握手:

1. 客户端发 SYN, 选择初始序号 x。
2. 服务器回 SYN+ACK, 选择初始序号 y, 确认 x+1。
3. 客户端回 ACK, 确认 y+1。

为什么不是两次:

- 防止旧的重复 SYN 报文导致服务器误建立连接。
- 双方都要确认自己的发送能力和对方接收能力。

### 6.5 TCP 连接释放

TCP 是全双工, 两个方向可分别关闭, 所以通常四次挥手:

```text
FIN -> ACK -> FIN -> ACK
```

half close 表示一方不再发送, 但仍可接收。

### 6.6 流量控制与拥塞控制

流量控制:

- 防止发送方把接收方缓冲区撑爆。
- 依赖接收窗口 rwnd。

拥塞控制:

- 防止网络内部过载。
- 依赖拥塞窗口 cwnd。

TCP 实际发送窗口通常:

```text
send window = min(rwnd, cwnd)
```

### 6.7 TCP 拥塞控制

慢启动 Slow Start:

- cwnd 从小开始。
- 每个 RTT 近似翻倍。
- 到达 ssthresh 后转拥塞避免。

拥塞避免 Congestion Avoidance:

- cwnd 线性增长, AIMD 中的 additive increase。

丢包后:

- 超时: ssthresh 减半, cwnd 退回小值, 重新慢启动。
- 三个重复 ACK: 快速重传, 快速恢复, cwnd 不一定退到 1 MSS。

AIMD:

- Additive Increase: 没拥塞时线性加。
- Multiplicative Decrease: 拥塞时乘法减。

## 7. 应用层

### 7.1 应用体系结构

Client/Server:

- 服务器长期在线, 固定地址。
- 客户端主动请求。

P2P:

- 节点既是客户端又是服务器。
- 扩展性好, 管理复杂。

### 7.2 DNS

DNS 把域名解析为 IP 地址。

层次结构:

- 根域名服务器
- 顶级域 TLD 服务器
- 权威 DNS 服务器
- 本地 DNS 服务器

查询方式:

- 递归查询: 被问服务器负责一路问到底。
- 迭代查询: 被问服务器返回下一步该问谁。

常见记录:

- A: 域名到 IPv4
- AAAA: 域名到 IPv6
- CNAME: 别名
- MX: 邮件服务器
- NS: 域名服务器

### 7.3 FTP

FTP 使用两个连接:

- 控制连接: 传命令, 通常端口 21。
- 数据连接: 传文件数据, 主动/被动模式不同。

FTP 的“两个连接、两个进程、两个端口”是常见考点。

### 7.4 Email

邮件系统组件:

- 用户代理 UA
- 邮件服务器
- SMTP
- POP3/IMAP

SMTP:

- 用于发送邮件和服务器之间转发。

POP3:

- 下载邮件, 简单。

IMAP:

- 邮件保留在服务器, 支持文件夹和多设备同步。

MIME:

- 扩展邮件格式, 支持附件、图片、非 ASCII 文本。

### 7.5 Web 与 HTTP

URL 标识资源位置。

HTTP 特点:

- 应用层协议。
- 请求-响应模式。
- 无状态, 但 cookie/session 可保存状态。

非持久连接:

- 每个对象单独建立 TCP 连接。
- 开销大。

持久连接:

- 多个对象复用一个 TCP 连接。
- 减少 RTT 开销。

HTTP 报文:

- 请求行: 方法、URL、版本。
- 状态行: 版本、状态码、短语。
- 首部字段。
- 空行。
- 实体体。

常见状态码:

- 200 OK
- 301/302 重定向
- 400 Bad Request
- 404 Not Found
- 500 Internal Server Error

### 7.6 DHCP

DHCP 自动分配 IP 配置。

典型过程 DORA:

1. Discover
2. Offer
3. Request
4. ACK

分配内容包括 IP 地址、子网掩码、默认网关、DNS 服务器、租期等。

## 8. 高频公式与题型

### 8.1 时延

```text
传输时延 = L / R
传播时延 = d / s
```

注意单位: bit、bps、秒。

### 8.2 奈奎斯特与香农

```text
Nyquist: C = 2B log2(V)
Shannon: C = B log2(1 + S/N)
dB = 10 log10(S/N)
```

### 8.3 子网

```text
主机位 = 32 - 前缀长度
地址数 = 2^主机位
传统可用主机数 = 2^主机位 - 2
```

### 8.4 分片

偏移字段单位是 8 字节。除最后一片外, 每片数据长度通常要是 8 的整数倍。

### 8.5 TCP

```text
发送窗口 = min(rwnd, cwnd)
```

慢启动指数增长, 拥塞避免线性增长。

## 9. 复习建议

网络这门课最容易“概念都认识, 做题不会”。建议每章抓一个核心动作:

- 第 1 章: 算时延、解释分层。
- 第 2 章: 算信道容量、画编码。
- 第 3 章: CRC/滑动窗口。
- 第 4 章: CSMA/CD、交换机学习、VLAN。
- 第 5 章: 子网划分、路由算法、IP 分片。
- 第 6 章: TCP 握手、可靠传输、拥塞控制。
- 第 7 章: DNS/HTTP/FTP/Email/DHCP 流程。

真正考试时, 看到题先判断它属于哪一层。层次判断对了, 解法通常就出来了。
