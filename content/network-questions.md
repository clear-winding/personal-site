## 一、网络概论与分层

1. 什么是协议？协议通常规定哪三类内容？

答案要点: 协议规定通信实体之间报文格式、报文发送/接收次序、收到报文或发生事件后的动作。

2. 解释网络边缘、网络核心和接入网络。

答案要点: 边缘是端系统和应用；核心是路由器/交换机和高速链路；接入网络把端系统接入核心网络。

3. 比较电路交换和分组交换。

答案要点: 电路交换建立专用电路、资源独占、适合稳定实时业务；分组交换按包共享链路、利用率高、可能排队丢包乱序。

4. 为什么 Internet 使用分组交换更合适？

答案要点: 数据业务突发性强；分组交换统计复用, 链路利用率高, 可扩展。

5. 一个 1500 Byte 分组在 10 Mbps 链路上的传输时延是多少？

答案要点: `1500*8 / 10^7 = 0.0012 s = 1.2 ms`.

6. 链路距离 3000 km, 信号传播速度 `2*10^8 m/s`, 传播时延是多少？

答案要点: `3*10^6 / (2*10^8) = 0.015 s = 15 ms`.

7. 端到端时延由哪几部分组成？

答案要点: 处理时延、排队时延、传输时延、传播时延。

8. OSI 七层模型从上到下是什么？

答案要点: 应用、表示、会话、传输、网络、数据链路、物理。

9. TCP/IP 五层模型从上到下是什么？

答案要点: 应用、传输、网络、数据链路、物理。

10. 什么是封装和解封装？

答案要点: 发送端每层给上层数据加本层首部；接收端每层去掉对应首部并交给上层。

## 二、物理层

11. 物理层接口特性包括哪四类？

答案要点: 机械特性、电气特性、功能特性、规程特性。

12. 一个无噪声 4 kHz 信道, 若使用 16 个离散电平, 最大数据率是多少？

答案要点: Nyquist `C=2B log2 V = 2*4000*4 = 32000 bps`.

13. 一个 4 kHz 有噪声信道, SNR = 30 dB, 最大数据率约是多少？

答案要点: `S/N=10^(30/10)=1000`; Shannon `C=4000*log2(1001)≈4000*9.97≈39.9 kbps`.

14. 为什么 Manchester 编码同步能力好但带宽开销大？

答案要点: 每个 bit 中间都有跳变, 接收端可用跳变同步；但信号变化频率高, 需要更大带宽。

15. NRZ 与 NRZI 的区别是什么？

答案要点: NRZ 用电平表示 0/1；NRZI 用是否翻转表示 bit, 更利于时钟恢复但长串无翻转仍有问题。

16. ASK、FSK、PSK、QAM 分别改变载波什么属性？

答案要点: 幅度、频率、相位、幅度和相位。

17. 比较 FDM 与 TDM。

答案要点: FDM 按频段划分, 用户同时不同频率；TDM 按时间片划分, 用户轮流使用全部频带。

18. 中继器和集线器工作在哪一层？主要作用是什么？

答案要点: 物理层。中继器再生信号；集线器是多端口中继器, 扩展物理连接但不隔离冲突域。

## 三、数据链路层

19. 数据链路层的主要功能有哪些？

答案要点: 成帧、差错控制、流量控制、可靠传输、介质访问控制。

20. 什么是成帧？列举两种成帧方法。

答案要点: 把 bit 流划分为帧并识别边界。方法有字节计数、字节填充、比特填充、编码违例等。

21. HDLC 的比特填充规则是什么？

答案要点: 标志为 `01111110`; 数据中连续出现五个 1 后插入一个 0, 接收端删除该 0。

22. 奇偶校验能检测哪些错误？不能可靠检测哪些错误？

答案要点: 能检测奇数个 bit 错误；偶数个 bit 错误可能漏检。

23. CRC 的基本思想是什么？

答案要点: 把数据看作二进制多项式, 乘以 `x^r` 后除以生成多项式, 余数作为校验序列。

24. Stop-and-Wait 为什么效率低？

答案要点: 每发一帧必须等待 ACK, 在 RTT 大或链路速率高时, 发送方大部分时间空闲。

25. 一帧发送时间 1 ms, RTT 为 49 ms, 忽略 ACK 发送时间, 停等协议利用率是多少？

答案要点: `U = 1 / (1+49) = 2%`.

26. GBN 和 SR 的核心区别是什么？

答案要点: GBN 接收方只接收按序帧, 丢一帧后后续乱序帧丢弃, 发送方回退重传；SR 可缓存乱序帧, 只重传真正丢失帧。

27. 若序号字段 3 bit, GBN 最大发送窗口是多少？SR 最大窗口通常是多少？

答案要点: 序号空间 8。GBN 最大 7；SR 最大 4。

28. PPP 是否提供可靠传输？它主要提供什么？

答案要点: PPP 本身不提供可靠传输；提供点到点成帧、链路控制、网络层协议协商等。

## 四、MAC 与局域网

29. MAC 协议要解决什么问题？

答案要点: 在广播共享信道中决定多个节点谁可以何时发送, 避免或处理冲突。

30. CSMA/CD 的含义是什么？

答案要点: Carrier Sense Multiple Access with Collision Detection。发送前监听, 发送时检测冲突。

31. CSMA/CD 中二进制指数退避如何工作？

答案要点: 第 m 次冲突后在 `[0, 2^k-1]` 随机选等待槽数, `k=min(m,10)`, 冲突越多平均等待越长。

32. 为什么无线网络使用 CSMA/CA 而不是 CSMA/CD？

答案要点: 无线发送时难以同时可靠监听冲突；信号衰减和隐藏终端使碰撞检测困难, 所以尽量避免碰撞。

33. 什么是隐藏终端问题？

答案要点: 两个发送端彼此听不到, 但都能到达同一接收端, 同时发送会在接收端冲突。

34. 以太网帧主要字段有哪些？

答案要点: 目的 MAC、源 MAC、类型/长度、数据、FCS, 还有前导码等物理同步部分。

35. 交换机如何学习 MAC 地址？

答案要点: 收到帧后记录源 MAC 与入端口的映射。

36. 交换机收到未知目的 MAC 的帧会怎么做？

答案要点: 泛洪到除入端口外所有端口。

37. 交换机收到目的 MAC 所在端口等于入端口的帧会怎么做？

答案要点: 过滤, 不转发。

38. STP 的作用是什么？

答案要点: 在有冗余链路的交换网络中构造无环生成树, 防止环路和广播风暴。

39. VLAN 的作用是什么？802.1Q 做了什么？

答案要点: VLAN 划分逻辑广播域, 实现隔离和管理；802.1Q 在帧中加入 VLAN tag。

## 五、网络层

40. 区分 routing、forwarding、switching。

答案要点: routing 是全网路径计算；forwarding 是路由器本地按转发表把包送到输出端口；switching 是更一般的数据交换过程。

41. Dijkstra 算法适合哪类路由？它需要什么信息？

答案要点: 链路状态路由；需要全网拓扑和链路代价。

42. 距离向量算法的核心递推公式是什么？

答案要点: `D_x(y)=min_v { c(x,v)+D_v(y) }`.

43. 距离向量算法有什么典型问题？如何缓解？

答案要点: count-to-infinity；可用 split horizon、poisoned reverse、触发更新等缓解。

44. IPv4 数据报中 TTL 字段有什么作用？

答案要点: 每经过一个路由器减 1, 到 0 丢弃并可发 ICMP, 防止环路无限转发。

45. 某 IP 数据报总长 4000 Byte, 首部 20 Byte, MTU 1500 Byte, 问如何分片？

答案要点: 数据部分 3980 Byte。每片最大数据 `1500-20=1480`, 且 1480 是 8 的倍数。分为 1480、1480、1020 三片。片总长分别 1500、1500、1040。偏移分别 0、185、370。前两片 MF=1, 最后一片 MF=0。

46. IP 地址 `192.168.10.77/26` 的网络地址、广播地址、可用主机范围是什么？

答案要点: `/26` 块大小 64。77 属于 64-127 段。网络地址 `192.168.10.64`; 广播 `192.168.10.127`; 可用 `192.168.10.65` 到 `192.168.10.126`。

47. 一个 `/24` 网络要划分至少 6 个子网, 每个子网至少 25 台主机, 可行的前缀长度是多少？

答案要点: 25 主机需主机位 h 满足 `2^h-2>=25`, h=5, 即 `/27`, 每子网 30 可用主机。`/24` 切 `/27` 可得 8 个子网, 满足至少 6 个。

48. 什么是最长前缀匹配？

答案要点: 路由表多项匹配目的 IP 时, 选择前缀长度最长即最具体的路由。

49. ARP 的作用和基本过程是什么？

答案要点: IP 地址解析为同一链路上的 MAC 地址。ARP request 广播, 持有该 IP 的主机单播 reply。

50. NAT 的优点和问题是什么？

答案要点: 节省公网 IPv4、隐藏内网；问题是破坏端到端原则, 入站连接和某些协议需要额外处理。

51. RIP、OSPF、BGP 分别属于什么类型？

答案要点: RIP 是距离向量 IGP；OSPF 是链路状态 IGP；BGP 是自治系统间路径向量 EGP。

## 六、传输层

52. 传输层和网络层的服务对象有什么不同？

答案要点: 网络层提供主机到主机；传输层提供进程到进程, 通过端口区分应用进程。

53. UDP 的主要特点是什么？适合哪些场景？

答案要点: 无连接、不保证可靠、首部小、延迟低、保留报文边界；适合 DNS、实时音视频、简单请求响应。

54. TCP 的主要特点是什么？

答案要点: 面向连接、可靠字节流、有序、流量控制、拥塞控制。

55. TCP 三次握手每一步发送什么？

答案要点: 客户端 SYN seq=x；服务器 SYN+ACK seq=y ack=x+1；客户端 ACK ack=y+1。

56. 为什么 TCP 建立连接需要三次握手？

答案要点: 双方都确认发送/接收能力, 防止旧连接请求报文导致错误建立连接。

57. TCP 四次挥手为什么常是四次？

答案要点: TCP 全双工, 一个方向关闭后另一个方向仍可能发送数据, 因此两个方向的 FIN/ACK 往往分开。

58. TCP 如何实现流量控制？

答案要点: 接收方通告接收窗口 rwnd, 发送方限制未确认数据量不超过接收能力。

59. TCP 拥塞控制中的 cwnd 和 ssthresh 分别是什么？

答案要点: cwnd 是拥塞窗口, 限制网络可承载的未确认数据；ssthresh 是慢启动阈值, 达到后转拥塞避免。

60. TCP 慢启动和拥塞避免增长方式有什么不同？

答案要点: 慢启动每 RTT 近似指数增长；拥塞避免每 RTT 线性增长。

61. 三个重复 ACK 通常触发什么机制？

答案要点: 快速重传, 并进入快速恢复, 不必等待超时。

62. 发送窗口由什么决定？

答案要点: `send window = min(rwnd, cwnd)`.

## 七、应用层

63. DNS 的作用是什么？常见记录类型有哪些？

答案要点: 域名解析为 IP 或其他资源记录。A、AAAA、CNAME、MX、NS。

64. 递归 DNS 查询和迭代 DNS 查询有什么区别？

答案要点: 递归由被问服务器负责继续查询并返回最终结果；迭代返回下一步应查询的服务器。

65. FTP 为什么说使用两个连接？

答案要点: 控制连接传命令, 数据连接传文件内容；控制连接通常端口 21。

66. SMTP、POP3、IMAP 分别用于什么？

答案要点: SMTP 用于发送/转发邮件；POP3 下载邮件；IMAP 在服务器上管理邮件并支持多设备同步。

67. MIME 解决了什么问题？

答案要点: 扩展邮件格式, 支持附件、图片、非 ASCII 文本等多媒体内容。

68. HTTP 是有状态还是无状态？如何实现用户登录状态？

答案要点: HTTP 本身无状态；可用 Cookie、Session、Token 等机制保存状态。

69. 非持久 HTTP 和持久 HTTP 的区别是什么？

答案要点: 非持久每个对象一个 TCP 连接；持久多个对象复用一个连接, 减少连接建立和 RTT 开销。

70. 写出 DHCP 的 DORA 四步。

答案要点: Discover, Offer, Request, ACK。

## 八、综合题

71. 从浏览器输入 URL 到页面显示, 涉及哪些主要协议和层次？

答案要点: DNS 解析域名应用层；TCP 建立连接传输层；HTTP 请求响应应用层；IP 路由网络层；以太网/Wi-Fi 数据链路层；物理层传输信号。

72. 主机 A 要给同一局域网主机 B 发送 IP 数据报, 已知 B 的 IP 但不知道 MAC, 过程是什么？

答案要点: A 查 ARP 缓存；若无, 广播 ARP Request；B 单播 ARP Reply；A 封装以太网帧目的 MAC 为 B 的 MAC 后发送。

73. 主机 A 要访问不同网络中的服务器 S, 以太网帧的目的 MAC 是谁？

答案要点: 下一跳默认网关的 MAC, 不是服务器 S 的 MAC。IP 目的地址仍是 S。

74. 为什么 TCP 可靠传输不能只靠 IP？

答案要点: IP 是尽力而为, 不保证交付、顺序、去重。TCP 在端系统通过序号、ACK、重传、窗口实现可靠字节流。

75. 解释“路由器工作在网络层, 交换机工作在数据链路层”在转发表依据上的差别。

答案要点: 路由器根据 IP 前缀和路由表转发；交换机根据 MAC 地址表转发帧。

76. 如果交换网络出现环路, 会发生什么？STP 如何解决？

答案要点: 广播帧可能无限循环, MAC 表震荡, 广播风暴。STP 阻塞部分冗余端口, 形成逻辑无环树。

77. 某 TCP 连接 MSS=1000 Byte, 初始 cwnd=1 MSS, 慢启动阈值 16 MSS, 无丢包时前 5 个 RTT 后 cwnd 分别约为多少？

答案要点: 1、2、4、8、16 MSS；达到阈值后转拥塞避免, 之后线性增加。

78. 如果一个网络题同时出现端口号、IP 地址、MAC 地址, 如何判断它们属于哪一层？

答案要点: 端口号属于传输层；IP 地址属于网络层；MAC 地址属于数据链路层。
