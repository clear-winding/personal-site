## 一、编译器总论

1. 什么是编译程序？它和解释程序的主要区别是什么？

答案要点: 编译程序把源语言程序翻译为语义等价的目标语言程序；解释程序直接按源程序或中间表示逐句执行。编译通常运行前完成, 解释运行时进行。

2. 画出典型编译器结构, 并说明前端和后端分别包括哪些阶段。

答案要点: 源程序 -> 词法 -> 语法 -> 语义 -> 中间代码 -> 优化 -> 目标代码。前端与源语言相关, 后端与目标机相关。

3. 为什么要引入中间代码？

答案要点: 降低前后端耦合；便于优化；便于移植；支持多源语言和多目标机器。

4. 什么是 compiler pass？多遍编译器有什么优缺点？

答案要点: pass 是对程序表示的一次扫描处理。多遍结构清晰、优化方便, 但可能增加时间和中间存储开销。

## 二、词法分析

5. 将字符串 `while (a12 <= 30) a12 = a12 + 1;` 划分为 token 序列。

答案要点: `while`, `(`, `id(a12)`, `<=`, `num(30)`, `)`, `id(a12)`, `=`, `id(a12)`, `+`, `num(1)`, `;`.

6. 写出 C 风格标识符的正规式: 第一个字符必须是字母或下划线, 后面可以是字母、数字或下划线。

答案要点: `(letter|_) (letter|digit|_)*`.

7. 说明正规式、NFA、DFA 三者的关系。

答案要点: 正规式描述正规语言；NFA/DFA 识别正规语言；三者表达能力等价。正规式可构造 NFA, NFA 可子集构造为 DFA。

8. 给出正规式 `(a|b)*abb` 所描述语言的含义。

答案要点: 由 a/b 构成且以 `abb` 结尾的所有串。

9. NFA 转 DFA 的子集构造法为什么会产生“状态集合”？

答案要点: NFA 在某输入后可能同时处于多个状态；DFA 的一个状态表示 NFA 可能状态集合。

10. 词法分析器为什么通常选择“最长匹配”？

答案要点: 避免把 `<=` 错拆成 `<` 和 `=`, 把 `int1` 错拆成关键字 `int` 和数字 `1`。最长匹配再结合优先级处理关键字/标识符。

## 三、文法基础

11. 给定文法 `S -> aSb | ε`, 写出它生成的语言。

答案要点: `{ a^n b^n | n >= 0 }`.

12. 什么是最左推导和最右推导？

答案要点: 最左推导每步替换最左非终结符；最右推导每步替换最右非终结符。

13. 判断文法 `E -> E+E | E*E | id` 是否二义, 并说明原因。

答案要点: 二义。`id+id*id` 可有不同语法树, 表示先加或先乘。

14. 写一个无二义表达式文法, 使 `*` 优先级高于 `+`, 且二者左结合。

答案要点:

```text
E -> E + T | T
T -> T * F | F
F -> (E) | id
```

15. BNF 和 EBNF 有什么区别？

答案要点: BNF 用产生式描述文法；EBNF 增加可选、重复、分组等记号, 写法更简洁, 表达能力与 CFG 描述相当。

## 四、自顶向下分析

16. 消除直接左递归: `A -> A a | A b | c | d`.

答案要点:

```text
A  -> c A' | d A'
A' -> a A' | b A' | ε
```

17. 对文法 `S -> iEtS | iEtSeS | a` 提取左公因子。

答案要点:

```text
S  -> iEtS S' | a
S' -> eS | ε
```

18. 计算文法 `E -> T E'`, `E' -> + T E' | ε`, `T -> id` 的 FIRST 集。

答案要点: `FIRST(T)={id}`; `FIRST(E)={id}`; `FIRST(E')={+, ε}`.

19. 计算上一题中 FOLLOW(E) 和 FOLLOW(E')。假设 E 是开始符号。

答案要点: `FOLLOW(E)={$}`; 因为 `E'` 在 `E -> T E'` 末尾, `FOLLOW(E')` 包含 `FOLLOW(E)`, 所以 `FOLLOW(E')={$}`。

20. LL(1) 文法中 “1” 表示什么？

答案要点: 分析时向前看 1 个输入 token 就能确定使用哪个产生式。

21. 什么情况下预测分析表某个格子出现冲突？

答案要点: 同一非终结符和输入符号对应多个产生式。常见原因是左递归、公共前缀、FIRST/FOLLOW 冲突或文法本身不适合 LL(1)。

## 五、自底向上与 LR 分析

22. 什么是移进-规约分析？

答案要点: 从输入串开始, 通过 shift 把符号入栈, 通过 reduce 把栈顶句柄规约为产生式左部, 最终规约到开始符号。

23. 什么是句柄？

答案要点: 在某个右句型中, 按最右推导逆过程下一步应被规约的子串。

24. LR(0) 项目 `A -> α . β` 中点的含义是什么？

答案要点: 点左边已识别, 点右边尚未识别。

25. 为什么 SLR(1) 比 LR(0) 冲突少？

答案要点: LR(0) 对规约项目在所有输入符号上规约；SLR 只在 FOLLOW(左部非终结符) 中规约。

26. LR(1) 项目比 LR(0) 项目多了什么信息？

答案要点: 多了向前看符号 lookahead, 形如 `[A -> α . β, a]`。

27. LALR(1) 的基本思想是什么？

答案要点: 合并 LR(1) 中核心项目相同的状态, 向前看符号取并集, 使状态数接近 SLR, 能力接近 LR(1)。

28. 解释 shift-reduce conflict 和 reduce-reduce conflict。

答案要点: 前者同一状态同一输入既可移进又可规约；后者可按多个产生式规约。

29. 为什么 Yacc/Bison 常使用 LALR(1)？

答案要点: 分析能力较强, 表规模比完整 LR(1) 小很多, 工程上折中好。

## 六、语义分析与符号表

30. 语义分析主要检查哪些问题？

答案要点: 声明与使用、作用域、类型匹配、函数参数、控制语句条件类型、返回类型等。

31. 符号表通常保存哪些信息？

答案要点: 名字、类别、类型、作用域、存储位置、参数列表、返回类型等。

32. 什么是综合属性？什么是继承属性？

答案要点: 综合属性从子节点传到父节点；继承属性从父节点或兄弟节点传到当前节点/子节点。

33. 给出声明语句 `int a,b,c;` 的语法制导翻译思路。

答案要点: `int` 产生类型属性, 通过继承属性传给变量列表；每遇到标识符就在符号表插入 `type=int`。

34. 为什么上下文无关文法无法单独检查变量先声明后使用？

答案要点: 这类约束依赖上下文和符号表信息, 超出了 CFG 的表达范围, 需要语义分析。

## 七、中间代码生成

35. 将 `x = a + b * c` 翻译为三地址码。

答案要点:

```text
t1 = b * c
t2 = a + t1
x = t2
```

36. 写出上一题的四元式。

答案要点:

```text
(*, b, c, t1)
(+, a, t1, t2)
(=, t2, -, x)
```

37. 将 `if a < b then x = 1 else x = 2` 翻译为四元式风格中间代码。

答案要点:

```text
(<, a, b, t1)
(Jf, t1, -, L_else)
(=, 1, -, x)
(J, -, -, L_after)
L_else:
(=, 2, -, x)
L_after:
```

38. 将 `while i < n do i = i + 1` 翻译为三地址码。

答案要点:

```text
L_begin:
t1 = i < n
ifFalse t1 goto L_after
t2 = i + 1
i = t2
goto L_begin
L_after:
```

39. 写出 `do { S } while (E)` 的控制流翻译模板。

答案要点:

```text
L_begin:
S.code
E.code
ifTrue E.place goto L_begin
```

40. 三地址码、四元式、三元式有什么关系？

答案要点: 三地址码是抽象形式；四元式显式给 result；三元式用语句编号表示中间结果, 不显式命名临时变量。

## 八、运行时系统

41. 静态分配、栈分配、堆分配分别适合什么对象？

答案要点: 静态分配适合编译期确定生命周期的全局/静态对象；栈分配适合过程调用中的局部变量和活动记录；堆分配适合生命周期不规则的动态对象。

42. 为什么递归需要栈式活动记录？

答案要点: 同一过程可能有多次未返回调用, 每次调用都需要独立保存参数、局部变量和返回位置。

43. 活动记录通常包含哪些内容？

答案要点: 返回地址、控制链、访问链、参数、局部变量、临时变量、保存寄存器等。

44. 引用计数 GC 为什么处理不了循环引用？

答案要点: 两个不可达对象互相引用时引用计数仍非 0, 无法回收。

45. 标记-清扫和复制收集各有什么优缺点？

答案要点: 标记-清扫不需要复制活对象但会产生碎片；复制收集整理空间、分配快, 但需要额外空间并复制活对象。

## 九、代码优化

46. 什么是基本块？如何划分基本块？

答案要点: 单入口单出口的连续语句序列。入口包括第一条语句、跳转目标、跳转后继语句；入口到下个入口前构成基本块。

47. 对下列代码做 DAG 局部优化:

```text
t1 = a + b
t2 = a + b
t3 = t2 * c
x = t1
y = t3
```

答案要点:

```text
t1 = a + b
t3 = t1 * c
x = t1
y = t3
```

48. 什么是公共子表达式删除？

答案要点: 如果同一表达式已计算且操作数未改变, 后续可复用旧结果, 不必重复计算。

49. 说明 reaching definitions 的含义。

答案要点: 若某赋值语句的定义沿某路径到达某程序点, 且途中该变量未被重新定义, 则该定义到达该点。

50. 说明 live variable 的含义。

答案要点: 若某变量当前值在未来某路径上会被使用, 且使用前未被重新定义, 则该变量在当前点活跃。

51. 什么是回边？它与循环有什么关系？

答案要点: 若节点 d 支配节点 n, 且有边 n -> d, 则该边为回边；回边通常对应自然循环。

52. 给出三种循环优化方法。

答案要点: 循环不变代码外提、强度削弱、删除归纳变量、循环展开。

## 十、目标代码生成

53. 目标代码生成阶段的三个关键问题是什么？

答案要点: 指令选择、寄存器分配、指令调度。

54. 什么是寄存器分配中的冲突图？

答案要点: 节点表示变量/临时变量；若两个变量活跃期重叠, 不能共用寄存器, 则连边。

55. 图着色寄存器分配中, K 种颜色代表什么？

答案要点: K 个可用寄存器。相邻节点不能同色。

56. 什么是 spilling？什么时候会发生？

答案要点: 寄存器不够时, 把某些变量存到内存, 用时再加载。冲突图无法用可用寄存器数着色时会发生。

57. 选择 spill 变量时应考虑哪些因素？

答案要点: 使用频率、是否在循环内、冲突数、定义/使用次数、加载存储代价。

58. 指令调度为什么不能随意重排指令？

答案要点: 必须保持数据依赖和控制依赖, 否则改变程序语义。

## 十一、综合题

59. 给出文法:

```text
E -> E + T | T
T -> T * F | F
F -> (E) | id
```

要求: 消除左递归, 并说明新文法中 `+` 和 `*` 的优先级是否改变。

答案要点:

```text
E  -> T E'
E' -> + T E' | ε
T  -> F T'
T' -> * F T' | ε
F  -> (E) | id
```

优先级不变, 因为 `E` 层处理加法, `T` 层处理乘法, `T` 嵌在 `E` 中。

60. 为 `for (i=0; i<n; i=i+1) S` 写中间代码模板。

答案要点:

```text
i = 0
L_begin:
t1 = i < n
ifFalse t1 goto L_after
S.code
t2 = i + 1
i = t2
goto L_begin
L_after:
```

61. 给定代码:

```text
1: a = b + c
2: d = b + c
3: e = a * d
4: b = 1
5: f = b + c
```

哪些公共子表达式可以删除？为什么第 5 行不能复用第 1 行结果？

答案要点: 第 2 行 `b+c` 可复用第 1 行结果；第 5 行前 `b` 被重新赋值, 操作数改变, 不能复用。

62. 写出一次函数调用时调用者和被调用者通常要保存的信息。

答案要点: 调用者准备实参、返回地址、可能保存 caller-saved 寄存器；被调用者建立活动记录、保存旧帧指针/控制链、保存 callee-saved 寄存器、分配局部变量空间。

63. 比较 LL(1) 与 LR(1)。

答案要点: LL(1) 自顶向下, 构造最左推导, 要求文法限制较强；LR(1) 自底向上, 构造最右推导逆过程, 能分析更大类文法, 表构造更复杂。

64. 说明从源程序到目标代码的每个阶段如何改变程序表示。

答案要点: 字符流 -> token 流 -> 语法树/分析树 -> 带属性语法树/符号表 -> IR/三地址码 -> 优化 IR -> 汇编/机器码。

## 十二、新资料补充题

65. 给出“以字母或下划线开头，后面可跟字母、数字或下划线”的标识符正规式。

答案要点: 可写为 `(letter|_)(letter|digit|_)*`。如果课程只允许基本符号，可把 letter 和 digit 进一步展开。

66. 为什么词法分析中 `ifx` 通常识别为标识符，而不是关键字 `if` 加标识符 `x`？

答案要点: 词法分析通常采用最长匹配原则。`ifx` 的最长匹配是一个标识符，之后再用关键字表区分 `if`。

67. 构造 LL(1) 分析表前，为什么常要先消除左递归和提取左公因子？

答案要点: 左递归会导致自顶向下分析无限递归；左公因子会导致只看一个向前看符号无法选择产生式。

68. LR 项目 `A -> α ·` 和 `B -> β · a γ` 出现在同一状态时，可能产生什么冲突？

答案要点: 如果向前看符号可能是 `a`，既可按 `A -> α` 规约，又可移进 `a`，可能产生移进-规约冲突。

69. 将 `for (i=0; i<n; i=i+1) S` 翻译成三地址码时，更新语句应放在什么位置？

答案要点: 初始化后进入条件判断；循环体执行后执行更新语句；更新后跳回条件判断。

70. 为什么做 DAG 优化时，变量重新赋值会破坏旧公共子表达式的复用？

答案要点: 公共子表达式成立要求操作数值未改变。若操作数变量被重新定义，旧表达式值不再保证等价。

71. 活动记录中为什么需要保存返回地址？

答案要点: 函数执行完必须回到调用点继续执行，返回地址用于恢复控制流。

72. 递归函数为什么不能只给局部变量分配一份静态空间？

答案要点: 多层递归调用同时存在，每层调用都有自己的参数、局部变量和返回现场，必须分别保存。

73. 什么是寄存器分配中的 spilling？

答案要点: 当可用寄存器不足以给所有同时活跃变量分配寄存器时，将部分变量临时放到内存中。

74. 指令调度为什么不能随意重排？

答案要点: 重排必须保持数据依赖和控制依赖，否则会改变程序语义。

75. 给定一个基本块，划分 leader 的三条规则是什么？

答案要点: 第一条语句是 leader；跳转目标是 leader；跳转语句的下一条是 leader。
