## Compile 编译原理

### 编译器流水线 {#compile-pipeline}

#### 从零理解

编译器就是把“人写的程序”翻译成“机器能执行的程序”。它通常按流水线工作：先把字符切成 token，再检查 token 能不能组成合法句子，再理解变量和类型，再生成中间代码，最后优化并变成目标代码。

```text
字符流 -> 词法分析 -> token 流 -> 语法分析 -> 语法树
语法树 -> 语义分析 -> 中间代码 -> 优化 -> 目标代码
```

#### 考试怎么考

常见考法是让你写出各阶段输入输出，或者判断某个错误在哪个阶段发现。变量没声明通常是语义分析，少了分号可能是语法分析，非法字符可能是词法分析。

#### 做题步骤

1. 先问输入是什么：字符、token、语法树、IR 还是目标代码。
2. 再问检查什么：拼写形式、语法结构、语义约束、运行效率。
3. 最后把错误放回对应阶段。

#### 小例子

`int x = y + 1;` 中，如果 `y` 没声明，词法和语法都可能通过，因为 token 和句子结构没有问题；真正报错的是语义分析。

### 正规式与正规集 {#compile-regular-expression}

#### 从零理解

正规式是描述“字符串集合”的公式。比如 `a|b` 表示可以是 `a` 或 `b`，`ab` 表示先来 `a` 再来 `b`，`a*` 表示零个或多个 `a`。正规集就是这个公式描述出来的所有字符串。

```text
a|b  -> {a, b}
ab   -> {ab}
a*   -> {ε, a, aa, aaa, ...}
(a|b)* -> 所有只由 a 和 b 组成的字符串
```

#### 考试怎么考

常见题型是“给语言写正规式”或“给正规式判断能接受哪些串”。关键词包括“至少一次”“可选”“以某字符开头/结尾”“不包含某模式”。

#### 做题步骤

1. 把题目语言拆成小条件，例如开头、主体、结尾。
2. 用连接表示顺序，用 `|` 表示选择，用 `*` 表示重复。
3. 如果是“至少一次”，写成 `aa*` 或 `a+`，课件若不用 `+` 就展开成基本符号。
4. 检查空串 `ε` 是否应该被接受。

#### 小例子

只由 `0` 和 `1` 组成，并且以 `01` 结尾的串：

```text
(0|1)*01
```

### NFA、DFA 与最长匹配 {#compile-nfa-dfa}

#### 从零理解

自动机可以理解成“读字符串的机器”。DFA 在每个状态读到某个字符时只有一个确定去处；NFA 可以有多个去处，也可以通过 `ε` 不读字符就跳转。NFA 更容易画，DFA 更容易实现。

#### 考试怎么考

重点是正规式转 NFA、NFA 子集构造转 DFA、DFA 识别字符串、词法分析里的最长匹配原则。

#### 做题步骤

1. NFA 读串时，把“当前可能状态集合”写出来。
2. 子集构造时，每个 DFA 状态都是一个 NFA 状态集合。
3. 每次先做 `ε-closure`，再按字符移动，再做 `ε-closure`。
4. 只要集合里含 NFA 终态，这个 DFA 状态就是终态。

#### 小例子

若读到 `ifx`，词法分析不能把前两个字符直接当关键字 `if`，因为最长匹配会优先得到标识符 `ifx`。如果输入是 `if (`，才会把 `if` 识别成关键字。

### FIRST、FOLLOW {#compile-first-follow}

#### 从零理解

`FIRST(X)` 表示从符号 `X` 开始，最终推导出的串第一个可能出现什么终结符。`FOLLOW(A)` 表示在某个句型里，非终结符 `A` 后面可能紧跟什么终结符。

```text
FIRST: 我自己开头能看到谁
FOLLOW: 我后面可能站着谁
```

#### 考试怎么考

常见题是给文法求 FIRST/FOLLOW，然后判断是否 LL(1)，或者填写预测分析表。

#### 做题步骤

1. 终结符的 FIRST 是它自己。
2. 如果 `A -> ε`，把 `ε` 放入 `FIRST(A)`。
3. 如果 `A -> X Y Z`，先把 `FIRST(X)` 除 `ε` 加进来；若 `X` 能空，再看 `Y`。
4. `FOLLOW(S)` 先放 `$`。
5. 若有 `A -> α B β`，把 `FIRST(β)` 除 `ε` 加进 `FOLLOW(B)`。
6. 若 `β` 能推出空，或 `B` 在产生式末尾，把 `FOLLOW(A)` 加进 `FOLLOW(B)`。

#### 小例子

```text
S -> A b
A -> a | ε
```

`FIRST(A) = {a, ε}`。因为 `S -> A b`，所以 `FOLLOW(A)` 包含 `b`。

### LL(1) 分析表 {#compile-ll1}

#### 从零理解

LL(1) 是一种自顶向下分析方法。第一个 L 表示从左到右读输入，第二个 L 表示构造最左推导，`1` 表示只看一个向前看符号就能决定用哪条产生式。

#### 考试怎么考

常见题是判断文法是不是 LL(1)，构造预测分析表，或模拟栈分析过程。

#### 做题步骤

1. 对每条产生式 `A -> α` 求 `FIRST(α)`。
2. 对每个 `a` 属于 `FIRST(α)` 且 `a != ε`，填 `M[A, a] = A -> α`。
3. 如果 `ε` 属于 `FIRST(α)`，对每个 `b` 属于 `FOLLOW(A)`，填 `M[A, b] = A -> α`。
4. 如果一个格子要填两条产生式，就不是 LL(1)。

#### 小例子

```text
A -> aB | ε
FOLLOW(A) = {b, $}
```

表里 `M[A,a]` 填 `A -> aB`，`M[A,b]` 和 `M[A,$]` 填 `A -> ε`。

### 左递归与左公因子 {#compile-left-recursion}

#### 从零理解

左递归是产生式一开始又回到自己，例如 `A -> Aα | β`。自顶向下分析遇到它会无限递归。左公因子是多条产生式开头相同，例如 `A -> αβ | αγ`，分析器看一个符号时不知道选哪条。

#### 考试怎么考

常见题是消除左递归、提取左公因子，然后继续构造 FIRST/FOLLOW 或 LL(1) 表。

#### 做题步骤

直接左递归模板：

```text
A  -> A α | β
A  -> β A'
A' -> α A' | ε
```

左公因子模板：

```text
A  -> α β | α γ
A  -> α A'
A' -> β | γ
```

#### 小例子

```text
E -> E + T | T
```

消除后：

```text
E  -> T E'
E' -> + T E' | ε
```

### LR 项目集与冲突 {#compile-lr-items}

#### 从零理解

LR 是自底向上分析：先把输入读进栈，再把右部规约成左部。项目里的点 `·` 表示“这条产生式已经识别到哪里”。点前面是已经看到的，点后面是接下来期待看到的。

```text
E -> E · + T
```

表示已经识别了一个 `E`，接下来如果看到 `+`，可以继续移进。

#### 考试怎么考

常见题是构造 LR(0) 项目集族、写 closure/goto、判断移进-规约冲突或规约-规约冲突，比较 SLR、LR(1)、LALR。

#### 做题步骤

1. 增广文法：加 `S' -> S`。
2. 初态是 `closure({S' -> · S})`。
3. `closure`：点后是非终结符 `B`，就把 `B -> · γ` 都加进来。
4. `goto(I, X)`：把项目集中点后为 `X` 的点越过 `X`，再做 closure。
5. 点在末尾表示可以规约；点后是终结符表示可以移进。

#### 小例子

一个状态里同时有：

```text
A -> α ·
B -> β · a γ
```

如果向前看符号可能是 `a`，就可能既想规约又想移进，这就是移进-规约冲突。

### 属性文法与语法制导翻译 {#compile-syntax-directed}

#### 从零理解

语法树只能说明结构，属性用来给树上的结点补信息。综合属性从孩子传给父亲，继承属性从父亲或兄弟传给当前结点。语法制导翻译就是在产生式旁边写语义动作，让语法分析时顺便算属性或生成代码。

#### 考试怎么考

常见题是区分综合/继承属性，按语义规则计算表达式值，或根据布尔表达式和控制语句生成中间代码。

#### 做题步骤

1. 找每个属性依赖谁。
2. 依赖孩子的是综合属性，依赖父亲或左兄弟的是继承属性。
3. 画依赖图时，箭头从“被依赖的属性”指向“要计算的属性”。
4. 生成代码题先定临时变量和标号，再按语法结构递归翻译。

#### 小例子

表达式 `3 + 4 * 5` 的值属性可以自底向上算：先算 `4 * 5 = 20`，再算 `3 + 20 = 23`。

### 三地址码与四元式 {#compile-three-address}

#### 从零理解

三地址码是一种中间代码，每条语句最多出现三个地址，例如 `x = y op z`。四元式把它拆成四列：操作符、参数1、参数2、结果。

```text
t1 = b * c
t2 = a + t1
x = t2
```

对应四元式：

```text
(*, b, c, t1)
(+, a, t1, t2)
(=, t2, _, x)
```

#### 考试怎么考

常见题是把表达式、if、while、do-while 翻译成三地址码，或把三地址码写成四元式。

#### 做题步骤

1. 表达式按优先级从内到外生成临时变量。
2. 条件语句先生成判断跳转，再生成 then/else 代码。
3. 循环一定先放循环入口标号，再放条件判断，最后跳回入口。
4. 四元式最后逐条拆成 `(op, arg1, arg2, result)`。

#### 小例子

`x = a + b * c`：

```text
t1 = b * c
t2 = a + t1
x = t2
```

### 活动记录与运行时存储 {#compile-runtime}

#### 从零理解

程序运行时，每次函数调用都需要一块空间保存局部变量、参数、返回地址、临时变量等，这块空间叫活动记录，也常叫栈帧。函数调用一层，栈上就压入一块；函数返回，就弹出一块。

#### 考试怎么考

常见题是画活动记录结构，判断静态分配、栈分配、堆分配适合什么数据，或解释递归为什么需要栈。

#### 做题步骤

1. 局部变量和返回地址一般在活动记录里。
2. 递归调用不能用单份静态空间，因为每层调用都要保留自己的变量。
3. 生命周期不确定、大小运行时才知道的数据更可能放堆。
4. 静态作用域看程序文本嵌套，动态作用域看调用链。

#### 小例子

递归 `fact(3)` 调用 `fact(2)` 再调用 `fact(1)`，三层调用的 `n` 必须各存一份，否则返回时就不知道每层原来的值。

### 基本块、CFG 与数据流分析 {#compile-data-flow}

#### 从零理解

基本块是一段“从第一条进、从最后一条出、中间没有跳转入口和出口”的连续代码。CFG 是控制流图，结点是基本块，边表示程序可能从一个块跳到另一个块。数据流分析是在 CFG 上反复传播信息，例如变量活跃性、到达定义。

#### 考试怎么考

常见题是划分基本块、画 CFG、用 DAG 做局部优化，或计算活跃变量集合。

#### 做题步骤

1. 找 leader：第一条语句、跳转目标、跳转语句下一条。
2. 每个 leader 到下一个 leader 前一条组成基本块。
3. 若块末尾是条件跳转，边连到跳转目标和下一块。
4. 活跃变量从后往前算：如果以后还会被用，它就是 live。

#### 小例子

```text
x = a + b
y = a + b
z = x + y
```

同一个基本块里，`a + b` 可只算一次，第二条可改成 `y = x`，这是公共子表达式消除。

### 寄存器分配与图着色 {#compile-register-allocation}

#### 从零理解

寄存器很快但数量少。寄存器分配就是决定哪些变量放寄存器，哪些变量暂时放内存。图着色把变量看成图的点，若两个变量生命周期重叠，就连一条边；相邻点不能用同一个寄存器。

#### 考试怎么考

常见题是根据活跃变量画冲突图，判断给定寄存器数量能不能完成分配，或说明 spilling 的含义。

#### 做题步骤

1. 先做活跃变量分析，找哪些变量同一时刻都要活着。
2. 活跃区间重叠的变量连边。
3. `k` 个寄存器就相当于用 `k` 种颜色给图染色。
4. 染不下时选择变量溢出到内存，这叫 spilling。

#### 小例子

如果 `a` 和 `b` 在同一条语句之后都还会被使用，它们不能共用一个寄存器。

## Network 计算机网络

### 分层模型 {#network-layering}

#### 从零理解

分层就是把复杂网络通信拆成多层，每层只关心自己的职责，并向上一层提供服务。发送时从上往下封装，接收时从下往上解封装。

```text
应用层: 产生应用数据
传输层: 进程到进程
网络层: 主机到主机、跨网络路由
链路层: 相邻节点传输
物理层: 比特变成信号
```

#### 考试怎么考

常见题是问协议属于哪一层、每层 PDU 叫什么、封装顺序是什么、路由器/交换机工作在哪层。

#### 做题步骤

1. 看到端口号，想到传输层。
2. 看到 IP 地址和路由，想到网络层。
3. 看到 MAC 地址、帧、CRC，想到链路层。
4. 看到信号、编码、带宽，想到物理层。

#### 小例子

浏览网页用 HTTP，这是应用层；HTTP 数据交给 TCP，TCP 报文段交给 IP，IP 数据报再封装成以太网帧。

### 时延、吞吐量与带宽 {#network-delay}

#### 从零理解

时延是“等多久”，吞吐量是“实际每秒传多少”，带宽是“链路理论上每秒最多传多少”。考试里最容易混的是传输时延和传播时延。

```text
传输时延 = 分组长度 / 链路速率 = L / R
传播时延 = 距离 / 信号传播速度 = d / s
总时延 = 处理 + 排队 + 传输 + 传播
```

#### 考试怎么考

常见题是给文件大小、链路速率、距离、传播速度，让你算端到端时延；或比较分组交换和电路交换。

#### 做题步骤

1. 先统一单位：bit、Byte、bps、秒。
2. 算每条链路的传输时延 `L/R`。
3. 算传播时延 `d/s`。
4. 多段链路按题目是否采用存储转发来相加。

#### 小例子

一个 1500 Byte 分组在 10 Mbps 链路上传输：

```text
L = 1500 * 8 = 12000 bit
传输时延 = 12000 / 10,000,000 = 0.0012 s = 1.2 ms
```

### 奈奎斯特与香农公式 {#network-nyquist-shannon}

#### 从零理解

奈奎斯特公式讨论无噪声信道：带宽越大、每个码元可表示的状态越多，数据率越高。香农公式讨论有噪声信道：信噪比越高，信道容量越大。

```text
Nyquist: C = 2B log2(V)
Shannon: C = B log2(1 + S/N)
dB = 10 log10(S/N)
```

#### 考试怎么考

常见题是根据带宽、信号级数、信噪比求最大数据率。给的是 dB 时要先换成普通比值。

#### 做题步骤

1. 无噪声、给信号级数 `V`，用奈奎斯特。
2. 有噪声、给信噪比，优先用香农。
3. 若给 dB，先算 `S/N = 10^(dB/10)`。
4. 若两种上限都给，实际最大值取较小者。

#### 小例子

带宽 `3000 Hz`，4 个信号级：

```text
C = 2 * 3000 * log2(4) = 12000 bps
```

### CRC 差错检测 {#network-crc}

#### 从零理解

CRC 把比特串看成多项式，用生成多项式去做模 2 除法。模 2 除法没有借位和进位，减法等同异或。发送方把余数附在数据后，接收方再除一次，余数为 0 就认为没有检测到错误。

#### 考试怎么考

常见题是给数据和生成多项式，让你求 CRC 校验码，或判断接收串是否出错。

#### 做题步骤

1. 生成多项式位数为 `r+1`，就在数据后补 `r` 个 0。
2. 用生成多项式做模 2 除法。
3. 得到的 `r` 位余数就是 CRC。
4. 发送串 = 原数据 + CRC。
5. 接收端用同一生成多项式除接收串，余数非 0 表示检测到错误。

#### 小例子

生成多项式 `1101` 有 4 位，所以 `r=3`，数据后面先补 3 个 0 再除。

### 滑动窗口、GBN、SR {#network-sliding-window}

#### 从零理解

滑动窗口让发送方不用等一个 ACK 才发下一个分组，可以连续发送多个。GBN 出错后从错的那个开始全部重传；SR 只重传出错的分组，效率更高但接收方要缓存乱序分组。

#### 考试怎么考

常见题是算窗口最大值、判断丢包后重传哪些帧、画发送窗口移动过程。

```text
GBN 最大窗口 = 2^k - 1
SR 最大窗口 = 2^(k-1)
```

#### 做题步骤

1. 看序号字段有 `k` 位，序号空间就是 `0` 到 `2^k - 1`。
2. GBN 接收方只按序接收，错了后面都不要。
3. SR 接收方可缓存乱序帧，所以窗口不能超过序号空间一半。
4. ACK 到来后，窗口左边界向右滑动。

#### 小例子

序号 3 位时，GBN 最大窗口为 `7`，SR 最大窗口为 `4`。

### CSMA/CD 与 CSMA/CA {#network-csma}

#### 从零理解

CSMA 的核心是“先听再说”。有线以太网早期用 CSMA/CD：发送时还能检测碰撞，发现碰撞就停发并退避。无线网络常用 CSMA/CA：无线很难边发边检测碰撞，所以尽量避免碰撞。

#### 考试怎么考

常见题是比较 CD 和 CA，解释冲突窗口、退避算法，或问为什么无线不能简单使用 CSMA/CD。

#### 做题步骤

1. 有线共享介质想到碰撞检测 CD。
2. 无线想到碰撞避免 CA、ACK、RTS/CTS。
3. 碰撞后不是立刻重发，而是随机退避。
4. 最短帧长与最大传播时延有关，保证发送者能检测到碰撞。

#### 小例子

无线场景有隐藏站问题：A 和 C 都能和 B 通信，但 A 和 C 互相听不到，可能同时给 B 发导致冲突，所以需要 CA 和 RTS/CTS 缓解。

### VLAN 与 STP {#network-vlan-stp}

#### 从零理解

VLAN 是在同一套交换机设备上划分多个逻辑局域网，减少广播范围。STP 是生成树协议，用来在交换机有冗余链路时阻塞部分链路，避免二层环路。

#### 考试怎么考

常见题是判断广播域、解释 trunk/access 端口、说明环路为什么危险、STP 为什么能保留冗余又避免环路。

#### 做题步骤

1. VLAN 划分广播域，不同 VLAN 间通信通常要三层设备。
2. access 口通常属于一个 VLAN，trunk 口可以承载多个 VLAN。
3. 交换机环路会导致广播风暴和 MAC 表震荡。
4. STP 选出无环树形拓扑，必要时阻塞冗余链路。

#### 小例子

两个部门接在同一台交换机上，但划入不同 VLAN，那么一个部门的广播不会直接泛洪到另一个部门。

### 路由算法 {#network-routing}

#### 从零理解

路由算法决定数据包下一跳走哪里。距离向量像“邻居告诉我到各地有多远”，链路状态像“大家都拿到完整地图后自己算最短路”。

#### 考试怎么考

常见题是 Dijkstra 最短路、距离向量表更新、比较 RIP/OSPF/BGP，或解释最长前缀匹配。

#### 做题步骤

1. Dijkstra：维护已确定集合，每次选当前距离最小的未确定节点。
2. 距离向量：用邻居的距离加上到邻居的代价，取最小。
3. 链路状态收敛快、开销较大；距离向量简单但可能慢收敛。
4. 路由表匹配多个前缀时，选最长前缀。

#### 小例子

若路由表有 `10.0.0.0/8` 和 `10.1.2.0/24`，目的地址 `10.1.2.8` 选 `/24`，因为它更具体。

### 子网与 CIDR {#network-subnet-cidr}

#### 从零理解

IP 地址分成网络号和主机号。CIDR 用 `/前缀长度` 表示网络号占多少位。前缀越长，网络越小，匹配越具体。

```text
主机位 = 32 - 前缀长度
地址数 = 2^主机位
传统可用主机数 = 2^主机位 - 2
网络地址 = IP & Mask
```

#### 考试怎么考

常见题是求网络地址、广播地址、可用主机范围、子网数量、最长前缀匹配。

#### 做题步骤

1. 先把前缀长度换成掩码。
2. IP 与掩码按位与，得到网络地址。
3. 主机位全 1 是广播地址。
4. 可用主机范围通常去掉全 0 和全 1。

#### 小例子

`192.168.1.130/26` 的块大小是 `64`，子网范围是 `192.168.1.128` 到 `192.168.1.191`，可用主机通常是 `.129` 到 `.190`。

### IP 分片 {#network-ip-fragment}

#### 从零理解

如果 IP 数据报太大，超过下一段链路 MTU，就要分片。每片都有自己的 IP 首部，片偏移以 8 Byte 为单位，除了最后一片，其他分片数据长度必须是 8 的整数倍。

#### 考试怎么考

常见题是给原始数据报长度、IP 首部长度、MTU，要求算每片总长度、数据长度、偏移、MF 标志。

#### 做题步骤

1. 每片最大数据 = `MTU - IP首部长度`。
2. 非最后一片数据长度向下取 8 的倍数。
3. 偏移 = 该片数据在原数据中的起始位置 / 8。
4. 前面分片 `MF=1`，最后一片 `MF=0`。

#### 小例子

MTU 为 1500，IP 首部 20，则每片最多带 1480 Byte 数据。因为 1480 能被 8 整除，所以可直接用。

### ARP、ICMP、NAT {#network-arp-icmp-nat}

#### 从零理解

ARP 用 IP 地址查 MAC 地址，解决同一链路上“下一跳的链路层地址是谁”。ICMP 用来报告网络层错误或做诊断。NAT 把内网私有地址转换成公网地址，常配合端口号区分不同内网主机连接。

#### 考试怎么考

常见题是问 ARP 请求/响应流程、ping 用什么协议、NAT 表如何转换地址和端口。

#### 做题步骤

1. 发给同网段主机，ARP 查目标主机 MAC。
2. 发给外网，ARP 查默认网关 MAC。
3. ping 主要用 ICMP Echo Request/Reply。
4. NAT 转换时记录内网 IP:端口 到公网 IP:端口的映射。

#### 小例子

访问外网服务器时，以太网帧的目的 MAC 通常是网关 MAC，而 IP 数据报的目的 IP 仍是外网服务器 IP。

### TCP 三次握手与释放 {#network-tcp-handshake}

#### 从零理解

TCP 是可靠传输协议，连接建立前双方要确认彼此的发送和接收能力。三次握手用 SYN 和 ACK 同步初始序号，也避免旧连接请求造成混乱。

```text
客户端 -> 服务器: SYN, seq=x
服务器 -> 客户端: SYN+ACK, seq=y, ack=x+1
客户端 -> 服务器: ACK, ack=y+1
```

#### 考试怎么考

常见题是画三次握手、填 seq/ack、解释为什么不是两次握手、画四次挥手和 TIME_WAIT。

#### 做题步骤

1. SYN 和 FIN 都会消耗一个序号。
2. ACK 号表示“我下一个想收到的字节序号”。
3. 三次握手第二次把服务器的 SYN 和 ACK 合在一起。
4. 连接释放通常四次，因为两个方向的数据流要分别关闭。

#### 小例子

若客户端发 `SYN seq=100`，服务器回复的确认号就是 `ack=101`。

### TCP 拥塞控制 {#network-tcp-congestion}

#### 从零理解

流量控制保护接收方，拥塞控制保护网络。TCP 用拥塞窗口 `cwnd` 控制最多能在网络里放多少未确认数据。发送窗口取接收窗口和拥塞窗口的较小值。

```text
发送窗口 = min(rwnd, cwnd)
```

#### 考试怎么考

常见题是画 cwnd 变化，区分慢启动、拥塞避免、快速重传、快速恢复，判断超时和三个重复 ACK 后如何调整窗口。

#### 做题步骤

1. 慢启动阶段，cwnd 近似按 RTT 指数增长。
2. 到达 ssthresh 后进入拥塞避免，cwnd 线性增长。
3. 超时通常认为拥塞严重，ssthresh 降低，cwnd 回到很小。
4. 三个重复 ACK 触发快速重传，通常比超时处理轻。

#### 小例子

若 `cwnd=16 MSS` 时超时，常见处理是 `ssthresh=8 MSS`，`cwnd` 回到 `1 MSS`，再慢启动。

### DNS、HTTP、DHCP {#network-dns-http-dhcp}

#### 从零理解

DNS 把域名解析成 IP 地址。HTTP 是浏览器和 Web 服务器之间传网页数据的应用层协议。DHCP 用来让主机自动获得 IP 地址、掩码、网关、DNS 服务器等配置。

#### 考试怎么考

常见题是 DNS 递归/迭代查询流程、HTTP 请求响应报文、HTTP 持久连接、DHCP 四步过程。

#### 做题步骤

1. 访问网站前，通常先 DNS 解析域名。
2. HTTP 请求包含方法、URL、首部和可选实体。
3. DHCP 经典流程是 Discover、Offer、Request、Ack。
4. 应用层协议要记住常见端口：HTTP 80，HTTPS 443，DNS 53，DHCP 67/68。

#### 小例子

新电脑接入网络后没有 IP，会先广播 DHCP Discover；服务器给 Offer，客户端 Request，服务器 Ack 后配置生效。

## RISC-V 组成与体系结构

### Amdahl 定律 {#riscv-amdahl}

#### 从零理解

Amdahl 定律说明：只优化程序的一部分，整体加速会被未优化部分限制。即使某部分优化到无限快，没优化的部分仍然要花时间。

```text
Sn = 1 / ((1 - Fe) + Fe / Se)
Fe: 被改进部分原来占总时间的比例
Se: 被改进部分自身加速比
```

#### 考试怎么考

常见题是给 `Fe` 和 `Se` 求总加速比，或求理论极限。

#### 做题步骤

1. 找被优化部分原占比 `Fe`。
2. 找这部分加速倍数 `Se`。
3. 代入公式。
4. 极限加速比是 `1 / (1 - Fe)`。

#### 小例子

80% 的时间被加速 4 倍：

```text
Sn = 1 / (0.2 + 0.8 / 4) = 1 / 0.4 = 2.5
```

### CPU 性能公式 {#riscv-cpu-performance}

#### 从零理解

CPU 运行时间由三件事决定：执行多少条指令、每条指令平均需要多少周期、每个周期多长。

```text
CPU time = IC * CPI * Clock Cycle Time
CPU time = IC * CPI / Clock Rate
```

#### 考试怎么考

常见题是比较两台机器快慢、根据指令类型比例求平均 CPI、计算优化后的运行时间。

#### 做题步骤

1. 如果有不同指令类别，先算平均 CPI。
2. 平均 CPI = 各类指令比例乘各自 CPI 后相加。
3. 再乘 IC 和周期时间，或除以频率。
4. 比较性能时，用运行时间更小者更快。

#### 小例子

`IC=10^9`，`CPI=2`，频率 `1 GHz`：

```text
CPU time = 10^9 * 2 / 10^9 = 2 s
```

### 补码与溢出 {#riscv-twos-complement}

#### 从零理解

补码让加减法可以统一用加法器完成。n 位补码最高位是符号位，范围是不对称的：负数比正数多一个。

```text
n 位补码范围 = -2^(n-1) 到 2^(n-1)-1
```

#### 考试怎么考

常见题是求补码表示、补码加减、判断溢出、把补码还原成十进制。

#### 做题步骤

1. 正数补码就是原二进制补足位数。
2. 负数补码：对应正数按位取反再加 1。
3. 同号相加得异号，说明溢出。
4. 最高位进位与次高位进位不同，也说明溢出。

#### 小例子

8 位补码中 `+127` 是 `01111111`，再加 `1` 得 `10000000`，它表示 `-128`，同号相加却得负数，所以溢出。

### IEEE 754 浮点数 {#riscv-ieee754}

#### 从零理解

浮点数类似科学计数法：符号位决定正负，阶码决定小数点移动多少，尾数决定有效数字。单精度是 32 位。

```text
1 位符号 + 8 位阶码 + 23 位尾数
value = (-1)^S * 1.fraction * 2^(E - 127)
```

#### 考试怎么考

常见题是把十进制数转成 IEEE 754，或根据二进制位还原数值。

#### 做题步骤

1. 先确定符号位。
2. 把绝对值转二进制，并规格化成 `1.x * 2^e`。
3. 阶码字段 = `e + 127`。
4. 尾数字段取小数点后的部分，不够补 0。

#### 小例子

`5.0 = 101.0_2 = 1.01 * 2^2`，所以符号位 `0`，阶码是 `2 + 127 = 129`，尾数从 `01` 开始后面补 0。

### 加法器与先行进位 {#riscv-adder}

#### 从零理解

加法器最慢的地方通常是进位传播。串行进位加法器要等低位进位一级级传到高位。先行进位用逻辑提前算出各位进位，速度更快但硬件更复杂。

```text
生成: G_i = A_i B_i
传递: P_i = A_i xor B_i
C_{i+1} = G_i + P_i C_i
```

#### 考试怎么考

常见题是写全加器表达式，比较串行进位和先行进位，或计算加法器延迟。

#### 做题步骤

1. 先写每位的和：`S_i = A_i xor B_i xor C_i`。
2. 再写进位：`C_{i+1} = A_iB_i + (A_i xor B_i)C_i`。
3. 串行进位延迟按位数累加。
4. 先行进位用更多门电路换更短延迟。

#### 小例子

低位 `1+1` 一定产生进位，这叫 generate；低位 `1+0` 如果输入有进位就会传给下一位，这叫 propagate。

### 寻址方式与有效地址 {#riscv-addressing}

#### 从零理解

寻址方式回答“操作数在哪里”。有效地址 EA 是真正要访问的内存地址。RISC-V 常见内存访问是基址加偏移，比如 `lw x1, 8(x2)` 表示从地址 `x2 + 8` 取数据。

#### 考试怎么考

常见题是判断立即数寻址、寄存器寻址、基址寻址、相对寻址，或计算 EA。

#### 做题步骤

1. 操作数直接写在指令里，是立即数。
2. 操作数在寄存器里，是寄存器寻址。
3. 地址由寄存器加偏移得到，是基址寻址。
4. 分支目标常和 PC 有关，是相对寻址。

#### 小例子

若 `x2 = 1000`，指令 `lw x1, 12(x2)` 的有效地址是 `1012`。

### RISC-V 指令格式 {#riscv-instruction-format}

#### 从零理解

RISC-V 指令长度常见为 32 位，不同指令类型把字段切成不同格式。理解格式的关键是看操作数来自哪里：寄存器、立即数、内存地址还是跳转偏移。

#### 考试怎么考

常见题是判断 R/I/S/B/U/J 型，写出 `rs1`、`rs2`、`rd`、立即数字段，或根据汇编解释指令行为。

#### 做题步骤

1. R-type：两个源寄存器，一个目的寄存器，如 `add rd, rs1, rs2`。
2. I-type：一个源寄存器，加立即数，如 `addi`、`lw`。
3. S-type：store，没有 `rd`，如 `sw rs2, imm(rs1)`。
4. B-type：条件分支，如 `beq rs1, rs2, label`。
5. U/J-type：大立即数或跳转，如 `lui`、`jal`。

#### 小例子

`sw x5, 8(x10)` 是 S-type，因为它把 `x5` 存到内存地址 `x10 + 8`，没有目的寄存器 `rd`。

### 总线、I/O、中断、DMA {#riscv-bus-io-dma}

#### 从零理解

总线是部件之间共享的通信通道。I/O 控制方式有程序查询、中断和 DMA。程序查询是 CPU 不断问设备好了没；中断是设备好了通知 CPU；DMA 是让专门控制器直接在内存和设备之间搬数据。

#### 考试怎么考

常见题是算总线带宽、比较查询/中断/DMA、解释中断响应流程。

```text
总线带宽 = 总线宽度(bit) * 频率 / 8
```

#### 做题步骤

1. 算带宽时注意 bit 和 Byte 换算。
2. 小量低速 I/O 可用查询。
3. 异步事件适合中断。
4. 大块高速数据传输适合 DMA，CPU 只负责开始和结束处理。

#### 小例子

64 bit 总线，频率 100 MHz，理论带宽：

```text
64 * 100,000,000 / 8 = 800,000,000 Byte/s
```

### Cache 映像与平均访问时间 {#riscv-cache}

#### 从零理解

Cache 是 CPU 和主存之间的小而快的存储器。程序常常反复访问附近的数据，Cache 利用时间局部性和空间局部性提升速度。映像方式决定主存块可以放到 Cache 的哪些位置。

```text
平均访问时间 TA = H*Tcache + (1-H)*Tmiss
offset = log2(块大小 Byte)
index/set = log2(行数或组数)
tag = 地址总位数 - offset - index/set
```

#### 考试怎么考

常见题是求 tag/index/offset 位数，比较直接映像、全相联、组相联，计算命中率和平均访问时间。

#### 做题步骤

1. 先确定块大小，算块内偏移位。
2. 直接映像用 Cache 行号做 index。
3. 组相联用组号做 index，组内再相联匹配 tag。
4. 全相联没有 index，只比较 tag。
5. 平均访问时间按命中和未命中概率加权。

#### 小例子

32 位地址，块大小 64 Byte，直接映像 Cache 有 1024 行：

```text
offset = log2(64) = 6
index = log2(1024) = 10
tag = 32 - 6 - 10 = 16
```

### 虚拟存储、页表、TLB {#riscv-virtual-memory}

#### 从零理解

虚拟存储让每个程序以为自己有连续的大地址空间。CPU 生成虚拟地址，页表把虚拟页号翻译成物理页框号。TLB 是页表项的高速缓存，减少查页表的时间。

#### 考试怎么考

常见题是虚拟地址划分、页号/页内偏移、页表项查询、TLB 命中率影响访问时间。

#### 做题步骤

1. 页大小决定页内偏移位数。
2. 虚拟地址高位是虚拟页号，低位是页内偏移。
3. 页表把虚拟页号映射到物理页框号。
4. 物理地址 = 物理页框号 + 原来的页内偏移。
5. TLB 命中就少一次查页表，未命中要访问页表。

#### 小例子

页大小 4 KB，所以页内偏移是 `12` 位。32 位虚拟地址中，高 `20` 位是虚拟页号。

### 微程序控制 {#riscv-microprogram}

#### 从零理解

控制器负责发出控制信号。硬布线控制器用逻辑电路直接产生控制信号，速度快但修改难。微程序控制把控制信号编码成微指令，存在控制存储器里，像执行小程序一样控制 CPU。

#### 考试怎么考

常见题是比较硬布线与微程序，解释微指令、微操作、控制存储器、微地址。

#### 做题步骤

1. 微操作是一个很小的硬件动作，如寄存器传送。
2. 微指令是一组同一拍可发出的控制信号。
3. 一条机器指令通常对应一段微程序。
4. 硬布线快，微程序灵活。

#### 小例子

取指令可能拆成几步微操作：PC 送地址寄存器，读内存，指令送 IR，PC 加 4。

### 流水线冒险 {#riscv-pipeline-hazards}

#### 从零理解

流水线把一条指令拆成多个阶段，让多条指令重叠执行。五级流水线常见为 IF、ID、EX、MEM、WB。冒险就是下一条指令不能按理想节奏推进。

```text
IF -> ID -> EX -> MEM -> WB
```

#### 考试怎么考

常见题是判断结构冒险、数据冒险、控制冒险，插入气泡，计算 CPI，解释转发和停顿。

#### 做题步骤

1. 结构冒险：硬件资源冲突。
2. 数据冒险：后面指令需要前面指令尚未写回的结果。
3. 控制冒险：分支跳转导致下一条指令地址不确定。
4. ALU 结果常可转发，load-use 通常还要停顿 1 周期。
5. 性能题用 `CPI = 理想CPI + 平均停顿周期`。

#### 小例子

```text
lw  x1, 0(x2)
add x3, x1, x4
```

`add` 立刻需要 `lw` 读出的数据，但 load 的数据到 MEM 阶段才回来，所以通常需要停顿 1 个周期。
